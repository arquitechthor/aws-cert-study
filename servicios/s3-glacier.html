Amazon S3 Glacier

En una frase: Archivo de muy bajo coste para datos fríos que recuperas en minutos u horas
Categoría: Almacenamiento (Storage)
Certificaciones: SAA-C03 SAP-C02 AIF-C01 CLF-C02
Documentación oficial: Documentación de Amazon S3 Glacier ↗
Aviso: hoy "S3 Glacier" significa las clases de almacenamiento de archivo de S3 (Simple Storage Service). El servicio original e independiente, Amazon Glacier (con bóvedas y archivos, y su propia API (Application Programming Interface: interfaz para que los programas se comuniquen)), no admite clientes nuevos desde el 07/11/2025. Para archivar se usan las clases Glacier dentro de un bucket de S3.

Qué es

Amazon S3 Glacier es la familia de clases de almacenamiento de archivo de S3: las más baratas por gigabyte, pensadas para datos que se guardan mucho tiempo y se consultan rara vez. A cambio del precio, el acceso es más caro o más lento. Ofrecen la misma durabilidad que el resto de S3 (once nueves), con los datos repartidos en al menos tres AZ (Availability Zone: zona de disponibilidad).

Conceptos clave

  • S3 Glacier Instant Retrieval: archivo con acceso en milisegundos, como S3 Standard, para datos que se leen alguna vez por trimestre (imágenes médicas, archivos de prensa). Duración mínima de almacenamiento: 90 días.
  • S3 Glacier Flexible Retrieval: los objetos no son accesibles al instante: hay que restaurarlos. Tres velocidades: acelerada (1 a 5 minutos), estándar (3 a 5 horas) y masiva (5 a 12 horas, gratuita). Duración mínima: 90 días. Típica para copias de seguridad y recuperación ante desastres.
  • S3 Glacier Deep Archive: la clase más barata de S3. Restauración estándar en unas 12 horas o masiva en unas 48. Duración mínima: 180 días. Para datos que se conservan siete o diez años por cumplimiento.
  • Restauración: en Flexible Retrieval y Deep Archive se pide una restauración y se obtiene una copia temporal durante los días que se indiquen; el objeto sigue archivado.
  • Capacidad aprovisionada: se compra para garantizar las restauraciones aceleradas cuando hagan falta.
  • Reglas de ciclo de vida: la forma habitual de llegar a Glacier: los objetos pasan solos de una clase a otra según su antigüedad y, al final, se borran.
  • Cargos a tener en cuenta: por recuperación (por gigabyte y por petición), por borrado anticipado si no se cumple la duración mínima, y unos kilobytes extra de metadatos por objeto, que hacen poco rentable archivar muchos objetos muy pequeños.
  • S3 Object Lock: modelo WORM (Write Once, Read Many: se escribe una vez y no se puede modificar) para que los datos archivados no se puedan borrar ni modificar durante el periodo de retención.

Casos de uso típicos

  • Archivo normativo a largo plazo: registros financieros, historias clínicas, grabaciones.
  • Sustituir las cintas magnéticas y sus bibliotecas.
  • Copias de seguridad antiguas que casi nunca se restauran.
  • Conservar a bajo coste los conjuntos de datos y las versiones de modelos de aprendizaje automático ya usados, por auditoría o reproducibilidad.

Cuándo NO usarlo

  • Datos de acceso frecuente: S3 Standard.
  • Patrón de acceso desconocido o cambiante: S3 Intelligent-Tiering, que mueve los objetos solo.
  • Datos de acceso poco frecuente pero inmediato y mensual: S3 Standard-IA.
  • Datos que se borran antes de 90 días: el cargo por borrado anticipado anula el ahorro.

Modelo de precios

Se paga el almacenamiento por gigabyte y mes (cada clase más barata que la anterior), las peticiones, la recuperación por gigabyte según la velocidad elegida, las transiciones de ciclo de vida y, si procede, el borrado anticipado. Cuanto más barato es guardar, más caro o lento es recuperar.

Seguridad y alta disponibilidad

  • Cifrado en reposo como en el resto de S3, con claves de S3 o de KMS (Key Management Service), y control de acceso con políticas de bucket e IAM (Identity and Access Management).
  • Durabilidad de once nueves, con copias en tres AZ o más.
  • Object Lock y el control de versiones protegen frente a borrados accidentales o malintencionados.
  • La replicación entre regiones también puede dejar la copia directamente en una clase Glacier.

Trampas de examen

  • "El menor coste" y "se puede esperar 12 horas o más": Deep Archive.
  • "Archivo, pero recuperable en minutos": Flexible Retrieval con restauración acelerada.
  • "Archivo con acceso inmediato en milisegundos": Glacier Instant Retrieval.
  • "Conservar durante siete años datos que casi nunca se consultan": regla de ciclo de vida hacia Deep Archive.
  • "No se debe poder borrar ni modificar": añade S3 Object Lock en modo de cumplimiento.
  • Un objeto en Flexible Retrieval o Deep Archive no se lee directamente: primero se restaura.
