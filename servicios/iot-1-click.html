AWS IoT 1-Click

En una frase: Dispositivos de un botón que lanzan una función con una simple pulsación
Categoría: Internet de las cosas (IoT) (Internet of Things (IoT))
Certificaciones: SAP-C02
Documentación oficial: Documentación de AWS IoT 1-Click ↗
Aviso: AWS IoT (Internet of Things: internet de las cosas: dispositivos conectados) 1-Click ya no está disponible. El servicio se retiró y su documentación redirige ahora a AWS IoT Core. Los dispositivos de un botón pueden integrarse hoy directamente con IoT Core y sus reglas (por ejemplo, para invocar una función Lambda). La guía se mantiene porque aparece en la guía de SAP-C02.

Qué es

AWS IoT 1-Click permitía usar dispositivos muy sencillos, sobre todo botones como el AWS IoT Enterprise Button, para disparar una función Lambda con una pulsación (simple, doble o larga), sin programar el dispositivo ni gestionar certificados. Ya está retirado.

Conceptos clave

  • Dispositivos listos de fábrica: venían preconfigurados para conectarse de forma segura.
  • Proyectos y ubicaciones: agrupaban dispositivos con atributos (por ejemplo, la sala donde estaban).
  • Acción: normalmente una función Lambda que recibía el tipo de pulsación y los atributos.
  • Hoy: dispositivos conectados a IoT Core con una regla que invoca Lambda.

Casos de uso típicos

  • Pedir reposición de material, avisar a limpieza o llamar a un técnico con un botón.
  • Registrar una incidencia en un sistema de tickets.

Cuándo NO usarlo

  • Ya no se puede usar: conecta los dispositivos a IoT Core.
  • Para dispositivos que envían telemetría continua: IoT Core desde el principio.

Comparativa con servicios parecidos

NecesidadOpción actual
Un botón que dispara una acciónDispositivo en IoT Core + regla que invoca Lambda

Modelo de precios

Se cobraba por dispositivo activo y año, más la invocación de Lambda.

Seguridad y alta disponibilidad

  • Los dispositivos venían con credenciales seguras de fábrica; en IoT Core se usan certificados X.509.

Trampas de examen

  • "Un botón que dispara una función Lambda sin programar el dispositivo": en la guía, IoT 1-Click.
  • "Hoy": IoT Core con una regla.
