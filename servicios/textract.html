Amazon Textract

En una frase: Extrae texto, tablas y campos de formularios de documentos escaneados
Categoría: Machine learning (Machine Learning)
Certificaciones: SAA-C03 SAP-C02 AIF-C01 CLF-C02
Documentación oficial: Documentación de Amazon Textract ↗

Qué es

Amazon Textract extrae automáticamente la información de documentos: PDF (Portable Document Format), escaneados y fotografías. Va más allá del reconocimiento óptico de caracteres clásico, que solo devuelve texto plano: entiende la estructura del documento y distingue qué es un campo de formulario y cuál es su valor, qué es una tabla y qué hay en cada celda. Reconoce texto impreso y manuscrito, sin plantillas ni configuración por tipo de documento.

Conceptos clave

  • Detección de texto: devuelve las líneas y las palabras, con su posición en la página.
  • Análisis de documentos, con funciones que se eligen en cada llamada:
    • Formularios: pares clave-valor ("Nombre: Ana Pérez").
    • Tablas: filas, columnas y celdas.
    • Consultas (queries): preguntas en lenguaje natural ("¿cuál es el número de póliza?") que devuelven solo ese dato.
    • Firmas: detecta dónde hay firmas.
    • Diseño (layout): títulos, párrafos, encabezados, listas.
  • API (Application Programming Interface: interfaz para que los programas se comuniquen) especializadas: para facturas y recibos (proveedor, total, líneas), para documentos de identidad y para documentación de préstamos hipotecarios.
  • Síncrono o asíncrono: las llamadas síncronas responden al momento para documentos de una página; las asíncronas procesan documentos de muchas páginas guardados en S3 (Simple Storage Service) y avisan por SNS (Simple Notification Service) al terminar.
  • Confianza: cada dato lleva un porcentaje de confianza. Con Amazon Augmented AI los resultados dudosos pasan a revisión humana.
  • Resultado: un JSON (JavaScript Object Notation: formato de datos en texto) de bloques relacionados entre sí (página, línea, palabra, celda).

Casos de uso típicos

  • Automatizar la entrada de datos de formularios, solicitudes y expedientes.
  • Procesar facturas y recibos para contabilidad.
  • Alta de clientes con extracción de datos del documento de identidad.
  • Digitalizar archivos en papel y hacerlos buscables.
  • Primer paso de una cadena: Textract extrae el texto, Comprehend lo analiza y un modelo de Bedrock lo resume o responde preguntas.

Cuándo NO usarlo

  • Texto en fotos de escenas (un cartel, una matrícula) junto con objetos y caras: Rekognition.
  • Si el texto ya es digital y solo hay que analizarlo: Comprehend.
  • Para traducirlo: Translate. Para historias clínicas: Comprehend Medical tras Textract.
  • Para audio: Transcribe.

Modelo de precios

Se paga por página procesada, con un precio según la función usada: la detección de texto es la más barata, y formularios, tablas, consultas y las API especializadas cuestan más.

Seguridad y alta disponibilidad

  • Acceso con IAM (Identity and Access Management); los trabajos asíncronos usan un rol para publicar en SNS y leen los documentos de S3.
  • Cifrado en tránsito y en reposo; los resultados se pueden guardar cifrados con KMS (Key Management Service) en tu bucket.
  • Acceso privado desde una VPC (Virtual Private Cloud) mediante PrivateLink.
  • Los documentos suelen contener datos personales: combina Textract con controles de acceso y, si procede, con el enmascarado de PII (Personally Identifiable Information: datos personales identificables) de Comprehend.

Trampas de examen

  • "Extraer datos de documentos escaneados, formularios o tablas": Textract.
  • "Texto manuscrito": Textract.
  • "Facturas y recibos": la API de gastos de Textract. "Pasaportes y carnés de conducir": la API de documentos de identidad.
  • "Documentos de cientos de páginas": operaciones asíncronas con S3 y SNS.
  • "Objetos o caras en una imagen": Rekognition, no Textract.
  • "Revisión humana cuando la confianza es baja": Amazon Augmented AI.
