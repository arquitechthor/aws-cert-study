AWS Cost Explorer

En una frase: Visualiza y filtra tu gasto de meses pasados y hace previsiones del próximo
Categoría: Administración financiera en la nube (Cloud Financial Management)
Certificaciones: SAA-C03 SAP-C02 AIF-C01 CLF-C02
Documentación oficial: Documentación de AWS Cost Explorer ↗

Qué es

AWS Cost Explorer es la herramienta para entender en qué se va el dinero. Muestra el coste y el uso en gráficas que se pueden filtrar y agrupar, permite comparar periodos, hace previsiones y da recomendaciones de ahorro. Es de consulta y análisis: no avisa ni limita el gasto, para eso está AWS Budgets.

Conceptos clave

  • Hay que activarlo una vez; a partir de ahí los datos se actualizan al menos una vez al día.
  • Histórico y previsión: muestra los últimos meses de gasto (trece por defecto, ampliables) y prevé hasta los doce meses siguientes a partir del histórico.
  • Granularidad: mensual o diaria, y por hora de los últimos 14 días como opción de pago.
  • Filtrar y agrupar: por servicio, cuenta, región, tipo de instancia, tipo de uso, etiqueta de asignación de costes o categoría de costes.
  • Informes guardados: vienen varios predefinidos (coste mensual por servicio, por cuenta) y puedes guardar los tuyos.
  • Informes de compromisos: utilización (cuánto se aprovecha lo comprado) y cobertura (qué parte del uso está cubierta) de instancias reservadas y Savings Plans.
  • Recomendaciones: de compra de Savings Plans y de instancias reservadas, y de ajuste de tamaño de instancias (con datos de Compute Optimizer).
  • API (Application Programming Interface: interfaz para que los programas se comuniquen) de Cost Explorer: los mismos datos para tus herramientas; se cobra por petición.
  • Etiquetas de asignación de costes: hay que activarlas en la consola de facturación para que aparezcan como dimensión; solo cuentan desde su activación.

Casos de uso típicos

  • Averiguar qué servicio o qué cuenta ha hecho subir la factura este mes.
  • Repartir el gasto entre equipos o proyectos mediante etiquetas.
  • Decidir cuánto comprometer en Savings Plans mirando el uso estable.
  • Prever el gasto del próximo trimestre.
  • Seguir el coste de las cargas de IA (entrenamiento, inferencia) por etiqueta o por servicio.

Cuándo NO usarlo

  • Para alertas y límites: AWS Budgets.
  • Para el máximo detalle (cada línea de la factura, por recurso y hora) y análisis con SQL (Structured Query Language: lenguaje de consultas de bases de datos relacionales): Cost and Usage Report con Athena.
  • Para estimar el coste de algo que aún no existe: AWS Pricing Calculator.
  • Para recomendaciones de tamaño recurso a recurso: Compute Optimizer.

Modelo de precios

La interfaz de la consola es gratuita. Se cobran las peticiones a la API y la granularidad por hora (según los registros de uso almacenados).

Seguridad y alta disponibilidad

  • El acceso se controla con IAM (Identity and Access Management), una vez habilitado el acceso de IAM a la facturación.
  • En una organización, la cuenta de administración ve el gasto de todas las cuentas y decide si las cuentas miembro pueden ver las recomendaciones, los descuentos y los reembolsos.
  • Solo muestra datos de facturación; no accede al contenido de los recursos.

Trampas de examen

  • "Visualizar", "analizar tendencias" o "identificar qué servicio genera más gasto": Cost Explorer.
  • "Prever el gasto de los próximos meses": Cost Explorer (previsión).
  • "Recomendación de compra de Savings Plans": Cost Explorer.
  • "Alertas": AWS Budgets. "El informe más detallado": Cost and Usage Report.
  • Para desglosar por equipo hacen falta etiquetas de asignación de costes activadas.
