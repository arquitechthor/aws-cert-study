Amazon Managed Grafana

En una frase: Paneles de observabilidad de código abierto gestionados, con varias fuentes de datos
Categoría: Administración y gobernanza (Management and Governance)
Certificaciones: SAA-C03 SAP-C02
Documentación oficial: Documentación de Amazon Managed Grafana ↗

Qué es

Amazon Managed Grafana es Grafana, la herramienta de código abierto de paneles de observabilidad, ofrecida como servicio gestionado. AWS se ocupa de los servidores, las actualizaciones, el escalado y la alta disponibilidad; tú creas espacios de trabajo y montas paneles que consultan y correlacionan métricas, logs y trazas de muchas fuentes a la vez, de AWS y de fuera. No almacena los datos: los lee de las fuentes.

Conceptos clave

  • Espacio de trabajo (workspace): un servidor de Grafana aislado, con su URL (Uniform Resource Locator: dirección web), sus usuarios y sus paneles.
  • Fuentes de datos: de AWS (CloudWatch, Amazon Managed Service for Prometheus, OpenSearch Service, X-Ray, Timestream, Athena, Redshift…) y de terceros o propias (Prometheus autogestionado, Graphite, Datadog, Splunk y otras mediante complementos).
  • Autenticación de usuarios: no usa usuarios de IAM (Identity and Access Management). Se entra con IAM Identity Center o con un proveedor de identidad compatible con SAML (Security Assertion Markup Language: estándar de inicio de sesión federado) 2.0 (o con ambos).
  • Roles de Grafana: administrador, editor y lector.
  • Permisos hacia las fuentes: gestionados por el servicio (crea por ti los roles de IAM para leer las fuentes de AWS) o gestionados por el cliente.
  • Varias cuentas: con AWS Organizations, un espacio de trabajo puede leer las fuentes de las cuentas de las OU (Organizational Unit: unidad organizativa de AWS Organizations) que indiques; los roles se despliegan con CloudFormation StackSets.
  • Alertas: reglas de alerta de Grafana sobre cualquier fuente, con avisos a SNS (Simple Notification Service) y a otros canales.
  • Red: el espacio de trabajo puede conectarse a una VPC (Virtual Private Cloud) para llegar a fuentes privadas, y el acceso de los usuarios se puede restringir por red.

Casos de uso típicos

  • Observabilidad de contenedores: métricas de EKS (Elastic Kubernetes Service) o ECS (Elastic Container Service) guardadas en Amazon Managed Service for Prometheus y vistas en Grafana.
  • Un panel único para varias cuentas, regiones y herramientas.
  • Equipos que ya usan Grafana y quieren dejar de mantener sus servidores.
  • Correlacionar una métrica con sus logs y sus trazas en la misma pantalla.

Cuándo NO usarlo

  • Si solo usas métricas de AWS y unos pocos paneles: los paneles de CloudWatch bastan y no añaden otro servicio.
  • Para almacenar métricas: Amazon Managed Service for Prometheus o CloudWatch. Grafana solo visualiza.
  • Para informes de negocio e inteligencia empresarial: Amazon Quick.
  • Para buscar en logs con paneles propios de OpenSearch: OpenSearch Dashboards.

Modelo de precios

Se paga por usuario activo al mes en cada espacio de trabajo, con dos tarifas: editor (administradores y editores) y lector. Cada espacio de trabajo factura como mínimo una licencia de editor. Las consultas a las fuentes se pagan en cada fuente (por ejemplo, las llamadas a la API (Application Programming Interface: interfaz para que los programas se comuniquen) de CloudWatch).

Seguridad y alta disponibilidad

  • Inicio de sesión único con el directorio corporativo; no hay contraseñas locales que gestionar.
  • El espacio de trabajo accede a las fuentes de AWS con roles de IAM, sin claves de larga duración.
  • Cada espacio de trabajo se despliega en varias AZ (Availability Zone: zona de disponibilidad) y AWS aplica las actualizaciones.
  • Los datos se cifran en tránsito y en reposo.

Trampas de examen

  • "Grafana" o "paneles de código abierto sin gestionar servidores": Managed Grafana.
  • La pareja habitual: Amazon Managed Service for Prometheus guarda las métricas y Managed Grafana las muestra.
  • "Visualizar en un solo panel datos de CloudWatch, Prometheus y una herramienta de terceros": Managed Grafana.
  • Los usuarios entran con IAM Identity Center o SAML, no con usuarios de IAM.
  • Si el enunciado pide lo nativo y más sencillo para métricas de AWS, la respuesta suele ser CloudWatch.
