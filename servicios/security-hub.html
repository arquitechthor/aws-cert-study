AWS Security Hub

En una frase: Reúne hallazgos de seguridad de varios servicios y puntúa tu cumplimiento de normas
Categoría: Seguridad, identidad y cumplimiento (Security, Identity, and Compliance)
Certificaciones: SAA-C03 SAP-C02 CLF-C02
Documentación oficial: Documentación de AWS Security Hub ↗
Aviso: AWS ha dividido el servicio en dos que se complementan. Security Hub CSPM (Cloud Security Posture Management: gestión de la postura de seguridad en la nube) es lo que las guías de examen llaman "AWS Security Hub": la gestión de la postura de seguridad, con estándares, controles y hallazgos agregados. El nuevo Security Hub (a secas) correlaciona esos hallazgos con los de otros servicios para priorizar los riesgos como exposiciones. En los exámenes, "Security Hub" sigue significando la vista única de hallazgos y de cumplimiento de estándares.

Qué es

AWS Security Hub da una visión completa del estado de seguridad de tus cuentas en un solo sitio. Hace dos cosas: agrega y normaliza los hallazgos de los servicios de seguridad de AWS y de productos de terceros, y comprueba automáticamente si tus recursos siguen las buenas prácticas de estándares de seguridad, con una puntuación. Así el equipo no tiene que saltar entre consolas ni formatos distintos.

Conceptos clave

  • Estándares de seguridad: conjuntos de controles. Entre ellos, las buenas prácticas fundamentales de seguridad de AWS, las referencias del CIS (Center for Internet Security: organización que publica referencias de configuración segura) para AWS, PCI DSS (Payment Card Industry Data Security Standard: norma de seguridad para datos de tarjetas) y NIST (National Institute of Standards and Technology: organismo de normas de EE. UU.).
  • Controles: cada comprobación concreta (por ejemplo, "los buckets no permiten lectura pública"). Se apoyan en reglas de AWS Config, así que AWS Config debe estar activado.
  • Puntuación de seguridad: el porcentaje de controles superados, por estándar y en total.
  • Hallazgos agregados: recibe los de GuardDuty, Inspector, Macie, IAM (Identity and Access Management) Access Analyzer, Firewall Manager, Systems Manager y productos de socios, en un formato común (el formato de hallazgos de AWS en la parte de postura; el esquema abierto OCSF (Open Cybersecurity Schema Framework: esquema abierto para datos de seguridad) en el nuevo Security Hub).
  • Exposiciones: el nuevo Security Hub cruza vulnerabilidades, configuraciones y amenazas para señalar los riesgos que de verdad son explotables.
  • Agregación entre regiones: los hallazgos de varias regiones se ven en una región de agregación.
  • Varias cuentas: con AWS Organizations, un administrador delegado ve y gestiona todas las cuentas, con configuración central.
  • Automatización: reglas de automatización que modifican hallazgos (cambiar gravedad, suprimir) y envío a EventBridge para avisar, abrir incidencias o corregir.
  • Información (insights): agrupaciones de hallazgos para ver tendencias.

Casos de uso típicos

  • Panel único de seguridad para toda la organización.
  • Medir y seguir el cumplimiento de CIS o PCI DSS.
  • Priorizar: qué hay que arreglar primero entre miles de hallazgos.
  • Enviar los hallazgos a la herramienta de incidencias o al sistema de gestión de eventos de seguridad de la empresa.

Cuándo NO usarlo

  • Para detectar amenazas: GuardDuty. Security Hub agrega; no analiza registros.
  • Para investigar un incidente: Detective.
  • Para reglas de configuración propias con corrección: AWS Config.
  • Para reunir evidencias de auditoría: Audit Manager o los paquetes de conformidad de AWS Config.
  • Para centralizar los registros de seguridad en bruto: Security Lake.

Modelo de precios

Se paga por el número de comprobaciones de seguridad realizadas y por los eventos de ingesta de hallazgos, con tramos por volumen (los hallazgos de las comprobaciones propias no se cobran como ingesta). Hay un periodo de prueba gratuito. Aparte está el coste de AWS Config, que debe estar activo.

Seguridad y alta disponibilidad

  • Es regional: se activa en cada región y se agrega en una.
  • Requiere AWS Config grabando los recursos para evaluar los controles.
  • Usa roles vinculados al servicio y no modifica tus recursos: informa.
  • Se pueden desactivar controles que no apliquen, con su justificación.

Trampas de examen

  • "Vista única", "panel centralizado de seguridad" o "agregar hallazgos de varios servicios": Security Hub.
  • "Comprobar el cumplimiento de CIS o de PCI DSS automáticamente": estándares de Security Hub.
  • "Hallazgos de todas las cuentas y regiones en un solo lugar": administrador delegado y agregación entre regiones.
  • Requisito: AWS Config activado.
  • GuardDuty detecta, Inspector analiza, Macie clasifica, Security Hub agrega, Detective investiga.
  • "Responder automáticamente a un hallazgo": EventBridge con Lambda o Systems Manager.
