Strands Agents

En una frase: SDK (Software Development Kit: bibliotecas para programar contra AWS) de código abierto para crear agentes de IA (inteligencia artificial) en Python con unas pocas líneas
Categoría: Herramientas para desarrolladores (Developer Tools)
Certificaciones: AIF-C01
Documentación oficial: Documentación de Strands Agents ↗

Qué es

Strands Agents es un SDK de código abierto creado por AWS para construir agentes de IA con poco código, en Python (y TypeScript). Sigue un enfoque dirigido por el modelo: defines el modelo, unas instrucciones y las herramientas disponibles, y es el modelo quien decide en un bucle qué herramienta usar y cuándo ha terminado, en lugar de programar el flujo paso a paso.

Conceptos clave

  • Agente: modelo + prompt de sistema + herramientas.
  • Bucle del agente: el modelo razona, llama herramientas, recibe resultados y repite hasta responder.
  • Herramientas: funciones Python marcadas con @tool, herramientas ya incluidas o servidores MCP (Model Context Protocol: protocolo abierto para dar herramientas y datos a agentes de IA).
  • Proveedores de modelos: Bedrock (por defecto), Anthropic, OpenAI, Ollama y otros.
  • Patrones multiagente: agentes como herramientas de otro agente, traspasos (handoffs), enjambres y grafos de agentes.
  • Observabilidad: trazas con OpenTelemetry.
  • Despliegue: en AgentCore Runtime, Lambda, Fargate o EC2 (Elastic Compute Cloud).

Casos de uso típicos

  • Asistentes que consultan sistemas internos mediante herramientas.
  • Agentes de operaciones que investigan incidencias con la CLI (Command Line Interface: línea de comandos) y registros.
  • Sistemas multiagente con un orquestador y especialistas.

Cuándo NO usarlo

  • Si no hace falta un agente (una sola llamada al modelo basta): la API (Application Programming Interface: interfaz para que los programas se comuniquen) de Bedrock.
  • Si el flujo es fijo y conocido: Step Functions con llamadas al modelo puede ser más predecible.
  • Strands no ejecuta ni protege el agente en producción por sí mismo: para eso, AgentCore.

Modelo de precios

El SDK es gratuito y de código abierto. Se pagan el modelo que use el agente y la infraestructura donde se despliegue.

Seguridad y alta disponibilidad

  • Limita las herramientas que das al agente al mínimo necesario.
  • Usa roles de IAM (Identity and Access Management) para las llamadas a AWS, no claves en el código.
  • Añade guardrails y revisión humana para acciones sensibles.

Trampas de examen

  • "SDK de código abierto de AWS para crear agentes": Strands Agents.
  • "El modelo decide qué herramienta usar": enfoque dirigido por el modelo.
  • "Llevar el agente a producción con memoria y aislamiento": AgentCore.
