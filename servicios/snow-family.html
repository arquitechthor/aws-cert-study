AWS Snow Family

En una frase: Dispositivos físicos resistentes para mover terabytes sin red o procesar en el borde
Categoría: Migración y transferencia (Migration and Transfer)
Certificaciones: SAA-C03 SAP-C02
Documentación oficial: Documentación de AWS Snow Family ↗
Aviso: AWS Snowball Edge no admite clientes nuevos, así que AWS ya no ofrece ningún dispositivo de Snow Family a quien no los usara (los clientes actuales pueden seguir pidiéndolos). Antes se retiraron Snowcone y Snowmobile. Alternativas para clientes nuevos: DataSync para transferencias en línea, AWS Data Transfer Terminal para llevar tus propios discos a una instalación de AWS, soluciones de socios y Outposts para cómputo en el borde. Las guías de examen todavía lo incluyen.

Qué es

AWS Snow Family son dispositivos físicos, resistentes y cifrados, que AWS envía a tus instalaciones. Copias en ellos los datos en local, los devuelves por mensajería y AWS los carga en S3 (Simple Storage Service). Sirven cuando la red no permite mover el volumen en un plazo razonable, y también para procesar datos en el borde en lugares sin conexión fiable (barcos, minas, zonas remotas). El dispositivo actual es Snowball Edge.

Conceptos clave

  • Snowball Edge optimizado para almacenamiento: mucha capacidad para migraciones de datos.
  • Snowball Edge optimizado para cómputo: más CPU (Central Processing Unit: procesador), memoria y opción de GPU (Graphics Processing Unit: procesador gráfico, muy usado en ML) para ejecutar instancias EC2 (Elastic Compute Cloud) y procesar en el borde.
  • Tipos de trabajo: importar a S3, exportar desde S3, o solo cómputo y almacenamiento local.
  • Interfaces de copia: adaptador compatible con S3, recurso NFS (Network File System: protocolo para compartir ficheros en red), y la herramienta gráfica AWS OpsHub.
  • Clústeres: varios dispositivos juntos para más capacidad y durabilidad local.
  • Regla práctica: si por la red tardarías más de una semana, valora una transferencia física.
  • Retirados: Snowcone (pequeño, portátil) y Snowmobile (un camión para exabytes) ya no se ofrecen.

Casos de uso típicos

  • Migrar cientos de terabytes o petabytes con poca red.
  • Recogida de datos en lugares remotos (sensores, vídeo) y envío periódico a AWS.
  • Procesamiento local con EC2 en el borde, desconectado.
  • Recuperar grandes volúmenes desde S3 a un centro de datos (exportación).

Cuándo NO usarlo

  • Si eres cliente nuevo: no está disponible.
  • Si la red permite hacer la transferencia en días: DataSync.
  • Para cómputo en el borde permanente, conectado a una región: Outposts.
  • Para replicación continua (no puntual): DataSync o Storage Gateway.

Modelo de precios

Se paga una tarifa por trabajo que incluye unos días de uso, los días adicionales, el envío y, en exportaciones, la transferencia de datos desde S3. La importación a S3 no tiene cargo de transferencia. Para uso prolongado hay precios por compromiso de 1 o 3 años.

Seguridad y alta disponibilidad

  • Los datos se cifran con claves de KMS (Key Management Service) que nunca se guardan en el dispositivo.
  • Carcasa resistente a manipulaciones, con TPM (Trusted Platform Module: chip que protege claves y comprueba la integridad del equipo) y etiqueta electrónica de envío.
  • Tras cargar los datos, AWS borra el dispositivo siguiendo las directrices del NIST (National Institute of Standards and Technology: organismo de normas de EE. UU.).
  • Un solo dispositivo no es redundante: conserva los datos de origen hasta confirmar la carga.

Trampas de examen

  • "Petabytes y conexión lenta" o "tardaría meses por la red": Snowball Edge.
  • "Procesar en un lugar sin conexión": Snowball Edge optimizado para cómputo.
  • "Exabytes": era Snowmobile (ya retirado).
  • "Red suficiente y copia recurrente": DataSync, no Snow.
  • Fuera del examen, recuerda que hoy un cliente nuevo usaría DataSync, Data Transfer Terminal o socios.
