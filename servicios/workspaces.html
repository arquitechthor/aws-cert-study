Amazon WorkSpaces

En una frase: Escritorios Windows o Linux completos en la nube accesibles desde cualquier equipo
Categoría: Computación para usuarios finales (End User Computing)
Certificaciones: CLF-C02 SAP-C02
Documentación oficial: Documentación de Amazon WorkSpaces ↗

Qué es

Amazon WorkSpaces ofrece escritorios virtuales en la nube (VDI (Virtual Desktop Infrastructure: escritorios virtuales alojados en servidores) gestionado). Cada usuario se conecta desde su portátil, una tableta, un cliente ligero o el navegador a un escritorio Windows o Linux que vive en AWS. Los datos no se quedan en el dispositivo, y AWS gestiona la infraestructura. Es parte de la familia WorkSpaces, junto a WorkSpaces Applications (antes AppStream 2.0) y WorkSpaces Secure Browser.

Conceptos clave

  • WorkSpaces Personal: escritorio persistente asignado a cada usuario, que conserva sus datos y aplicaciones.
  • WorkSpaces Pools: escritorios no persistentes que se reparten entre usuarios; útiles para turnos, formación o centros de contacto.
  • Facturación: AlwaysOn (tarifa mensual, para uso a diario) o AutoStop (cuota mensual pequeña más pago por horas, se apaga si no se usa).
  • Paquetes (bundles): combinaciones de CPU (Central Processing Unit: procesador), memoria, almacenamiento y sistema operativo, incluidos con GPU (Graphics Processing Unit: procesador gráfico, muy usado en ML).
  • Directorio: se integra con Active Directory mediante Directory Service (AD Connector o Managed Microsoft AD); MFA (Multi-Factor Authentication: inicio de sesión con un segundo factor) con RADIUS (Remote Authentication Dial-In User Service: protocolo de autenticación en red) o SAML (Security Assertion Markup Language: estándar de inicio de sesión federado).
  • Protocolos de streaming: DCV (antes WSP (WorkSpaces Streaming Protocol: nombre anterior del protocolo DCV en WorkSpaces)) y PCoIP (PC over IP: protocolo de Teradici para transmitir escritorios).
  • BYOL (Bring Your Own License: usar tu propia licencia): llevar licencias propias de Windows.

Casos de uso típicos

  • Teletrabajo y contratistas que no deben guardar datos en sus equipos.
  • Fusiones y adquisiciones: dar escritorios estándar rápidamente.
  • Escritorios con GPU para diseño o ingeniería.
  • Sustituir una VDI local.

Cuándo NO usarlo

  • Si solo hay que publicar una o varias aplicaciones, no un escritorio completo: WorkSpaces Applications.
  • Si solo se necesita acceder de forma segura a webs internas: WorkSpaces Secure Browser.
  • Para dar acceso de red a las VPC (Virtual Private Cloud) desde el portátil: Client VPN (Virtual Private Network: red privada virtual).

Modelo de precios

WorkSpaces Personal: AlwaysOn con tarifa mensual por escritorio o AutoStop con cuota mensual más horas de uso. Pools: por hora de uso y por usuario. Las licencias de Windows pueden ir incluidas o ser propias (BYOL).

Seguridad y alta disponibilidad

  • Los datos se quedan en AWS, no en el dispositivo del usuario.
  • Volúmenes cifrados con KMS (Key Management Service).
  • Control de acceso por IP (Internet Protocol: dirección de red) y por dispositivo de confianza (certificados).
  • MFA a través del directorio o del proveedor SAML.
  • Despliegue en subredes de dos AZ (Availability Zone: zona de disponibilidad); los escritorios personales tienen copias automáticas de sus volúmenes.

Trampas de examen

  • "Escritorios virtuales" o "VDI": WorkSpaces.
  • "Usuarios que trabajan pocas horas al mes": facturación AutoStop.
  • "Uso diario a tiempo completo": AlwaysOn.
  • "Solo una aplicación en el navegador": WorkSpaces Applications, no un escritorio completo.
  • "Usar las cuentas del Active Directory local": AD Connector.
