Amazon ECR

Amazon Elastic Container Registry (Amazon ECR)

En una frase: Registro privado de imágenes Docker con escaneo de vulnerabilidades y réplica
Categoría: Contenedores (Containers)
Certificaciones: CLF-C02 SAA-C03 DVA-C02 SAP-C02
Documentación oficial: Documentación de Amazon ECR ↗

Qué es

Amazon Elastic Container Registry (ECR) es un registro gestionado de imágenes de contenedores (y otros artefactos OCI (Open Container Initiative: estándar abierto de imágenes de contenedores)). Guardas tus imágenes en repositorios privados controlados con IAM (Identity and Access Management), o las publicas en ECR Public. ECS (Elastic Container Service), EKS (Elastic Kubernetes Service), Lambda y App Runner descargan las imágenes directamente de ECR. Las imágenes se guardan en S3 (Simple Storage Service), de forma duradera y cifrada.

Conceptos clave

  • Repositorio, imagen y etiqueta: cada imagen se identifica por su etiqueta (por ejemplo v1.2) o por su resumen criptográfico.
  • Etiquetas inmutables: impiden sobrescribir una etiqueta existente.
  • Escaneo de imágenes: básico, o mejorado con Amazon Inspector (continuo, incluye paquetes del lenguaje).
  • Políticas de ciclo de vida: borran imágenes antiguas o sin etiqueta para ahorrar.
  • Replicación: entre regiones y entre cuentas.
  • Caché de extracción (pull through cache): guarda copias de imágenes de registros públicos (Docker Hub, ECR Public…) en tu ECR.
  • Autenticación de Docker: con aws ecr get-login-password, que da un token temporal.
  • Políticas de repositorio: dan acceso a otras cuentas o servicios.

Casos de uso típicos

  • Guardar las imágenes que se despliegan en ECS, EKS o Lambda.
  • CI/CD (Continuous Integration / Continuous Delivery: integración y entrega continuas): CodeBuild construye la imagen y la sube; la canalización la despliega.
  • Compartir imágenes base entre las cuentas de una organización.
  • Publicar imágenes de código abierto en ECR Public.

Cuándo NO usarlo

  • Para paquetes de lenguajes (npm, Maven, PyPI): CodeArtifact.
  • Para ejecutar contenedores: ECS, EKS o Fargate; ECR solo los guarda.

Modelo de precios

Se paga el almacenamiento de las imágenes por GB y mes y la transferencia de datos de salida (la descarga desde la misma región hacia servicios de AWS no se cobra). El escaneo mejorado se cobra con las tarifas de Inspector.

Seguridad y alta disponibilidad

  • Acceso con IAM y políticas de repositorio; tokens de Docker temporales.
  • Cifrado en reposo con claves de S3 o de KMS (Key Management Service).
  • Puntos de enlace de VPC (Virtual Private Cloud) para descargar imágenes sin salir a internet.
  • Servicio regional de alta disponibilidad; replicación a otras regiones para recuperación.

Trampas de examen

  • "Registro privado de imágenes Docker": ECR.
  • "Buscar vulnerabilidades en las imágenes": escaneo de ECR (mejorado con Inspector).
  • "Borrar imágenes antiguas automáticamente": políticas de ciclo de vida.
  • "Evitar que se sobrescriba una etiqueta": etiquetas inmutables.
  • "Instancias en subredes privadas sin NAT (Network Address Translation: traducción de direcciones de red) descargan imágenes": puntos de enlace de VPC de ECR (y el de puerta de enlace de S3).
  • "docker push falla por autenticación": obtener el token con get-login-password.
