AWS Transform

En una frase: Agentes de IA (inteligencia artificial) que modernizan código heredado: .NET, mainframe y cargas de VMware
Categoría: Machine learning (Machine Learning)
Certificaciones: AIF-C01
Documentación oficial: Documentación de AWS Transform ↗

Qué es

AWS Transform es un servicio de IA con agentes que acelera la modernización y la migración de sistemas heredados. Varios agentes especializados analizan el código o la infraestructura, proponen un plan, ejecutan la transformación y documentan el resultado, con personas que revisan y aprueban en los puntos clave.

Conceptos clave

  • .NET (Windows): pasa aplicaciones .NET Framework a .NET multiplataforma, para ejecutarlas en Linux y ahorrar licencias.
  • Mainframe: analiza código COBOL (Common Business-Oriented Language: lenguaje de programación habitual en mainframes), documenta la lógica de negocio, descompone y refactoriza hacia Java.
  • VMware: descubre máquinas y dependencias, traduce la red y planifica olas para pasar a EC2 (Elastic Compute Cloud).
  • Migraciones: descubrimiento, evaluación de costes (TCO) y rehospedaje usando Transform MGN.
  • Transformaciones personalizadas (custom): actualizaciones de Java, Python o Node.js y transformaciones propias descritas en lenguaje natural, aplicadas a muchos repositorios.
  • Humano en el bucle: los planes y cambios se revisan antes de aplicarse.

Casos de uso típicos

  • Salir de licencias de Windows modernizando aplicaciones .NET.
  • Documentar y modernizar aplicaciones de mainframe.
  • Migrar un centro de datos VMware a AWS.
  • Actualizar Java 8 a una versión moderna en cientos de repositorios.

Cuándo NO usarlo

  • Para cambios puntuales en un proyecto: un asistente de programación como Kiro o Q Developer.
  • Para mover datos o bases de datos: DataSync, DMS (Database Migration Service).

Modelo de precios

Depende del tipo de transformación: algunas no tienen coste adicional y otras se cobran por uso del agente (por ejemplo, por líneas de código o por tiempo de transformación). Se pagan aparte los recursos de AWS creados.

Seguridad y alta disponibilidad

  • El código se procesa en tu entorno de AWS y no se usa para entrenar modelos.
  • Acceso controlado por IAM (Identity and Access Management) e IAM Identity Center.
  • Revisión humana de los planes y del código transformado.

Trampas de examen

  • "Modernizar .NET Framework a .NET multiplataforma con IA": AWS Transform.
  • "Documentar y modernizar COBOL": AWS Transform for mainframe.
  • "Migrar VMware a EC2 con planificación de olas": AWS Transform for VMware.
  • "Actualizar Java en cientos de repositorios": transformaciones personalizadas.
