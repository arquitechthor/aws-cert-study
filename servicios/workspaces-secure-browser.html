Amazon WorkSpaces Secure Browser

En una frase: Navegador aislado en la nube para usar webs internas sin dejar datos en el equipo
Categoría: Computación para usuarios finales (End User Computing)
Certificaciones: CLF-C02
Documentación oficial: Documentación de Amazon WorkSpaces Secure Browser ↗

Qué es

Amazon WorkSpaces Secure Browser (antes WorkSpaces Web) ofrece un navegador que se ejecuta en AWS y se transmite al navegador local del usuario. Sirve para acceder a sitios web internos y aplicaciones SaaS (Software as a Service: software que se usa como servicio) sin VPN (Virtual Private Network: red privada virtual) y sin que los datos queden en el dispositivo: no hay caché, descargas ni cookies locales. Es de pago por usuario y no hay infraestructura que gestionar.

Conceptos clave

  • Portal web: la dirección a la que se conectan los usuarios.
  • Proveedor de identidad: inicio de sesión con SAML (Security Assertion Markup Language: estándar de inicio de sesión federado) 2.0 (o IAM Identity Center).
  • Configuración de red: el navegador sale desde tu VPC (Virtual Private Cloud), así que llega a webs internas.
  • Políticas del navegador: qué sitios se permiten, marcadores y extensiones.
  • Configuración de usuario: portapapeles, descargas, subidas e impresión.
  • Registros de sesión para auditoría.

Casos de uso típicos

  • Contratistas o personal temporal que necesitan una web interna desde sus propios equipos.
  • Acceso seguro a SaaS con datos sensibles sin que se descarguen.
  • Sustituir la VPN cuando solo se necesita navegar por aplicaciones web.

Cuándo NO usarlo

  • Si se necesitan aplicaciones de escritorio: WorkSpaces Applications o WorkSpaces.
  • Si se necesita acceso de red completo a la VPC: Client VPN.
  • Para dar acceso a aplicaciones web propias con políticas de confianza cero, sin aislar el navegador: Verified Access.

Modelo de precios

Se paga una tarifa mensual por usuario activo (quien inicia sesión al menos una vez en el mes), sin compromisos ni cargos por infraestructura.

Seguridad y alta disponibilidad

  • Sesiones efímeras: al cerrar, no queda nada en AWS ni en el dispositivo.
  • Inicio de sesión con el proveedor corporativo y MFA (Multi-Factor Authentication: inicio de sesión con un segundo factor).
  • Control de portapapeles, descargas e impresión para evitar fugas.
  • El tráfico hacia las webs internas sale de tu VPC; no hace falta exponerlas.

Trampas de examen

  • "Acceder a webs internas desde equipos no gestionados sin dejar datos": WorkSpaces Secure Browser.
  • "Sin VPN, solo navegación web": Secure Browser.
  • "Aplicación de escritorio": WorkSpaces Applications.
  • "Pago por usuario al mes": Secure Browser.
