AWS IoT Things Graph

En una frase: Conecta visualmente dispositivos y servicios web en flujos sin programar
Categoría: Internet de las cosas (IoT) (Internet of Things (IoT))
Certificaciones: SAP-C02
Documentación oficial: Documentación de AWS IoT Things Graph ↗
Aviso: AWS IoT Things Graph se retiró en 2022 (sus API (Application Programming Interface: interfaz para que los programas se comuniquen) se marcaron como obsoletas el 30/08/2022) y AWS orienta ahora a AWS IoT TwinMaker; su documentación redirige allí. La guía se mantiene porque el servicio aparece en la guía de SAP-C02.

Qué es

AWS IoT Things Graph era una herramienta para crear aplicaciones de IoT (Internet of Things: internet de las cosas: dispositivos conectados) de forma visual: arrastrando modelos de dispositivos (cámaras, sensores, pantallas) y de servicios web a un lienzo y conectándolos en flujos. Los flujos se desplegaban en la nube o en un dispositivo con Greengrass. Se retiró en 2022.

Conceptos clave

  • Modelos: representaban dispositivos y servicios con sus acciones, eventos y estados, ocultando las diferencias entre marcas.
  • Flujos: la lógica que conectaba modelos.
  • Despliegue: en la nube o en el borde con Greengrass.
  • Hoy: IoT TwinMaker para gemelos digitales que conectan datos de equipos; la lógica se construye con IoT Core, Greengrass y Step Functions.

Casos de uso típicos

  • Conectar sin programar una cámara y un sensor de movimiento para que la cámara grabe al detectar algo.

Cuándo NO usarlo

  • Ya no se puede usar.
  • Para gemelos digitales de instalaciones: IoT TwinMaker.
  • Para orquestar flujos visuales en la nube: Step Functions.

Modelo de precios

Se cobraba por pasos de flujo ejecutados y por mensajes.

Seguridad y alta disponibilidad

  • Usaba la identidad y los permisos de IoT Core y Greengrass.

Trampas de examen

  • "Conectar visualmente dispositivos de distintos fabricantes sin programar": en la guía, IoT Things Graph.
  • "Gemelo digital": IoT TwinMaker.
