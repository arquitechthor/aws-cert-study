AWS Migration Hub

En una frase: Panel único para seguir el progreso de todas tus migraciones de aplicaciones
Categoría: Migración y transferencia (Migration and Transfer)
Certificaciones: CLF-C02 SAP-C02
Documentación oficial: Documentación de AWS Migration Hub ↗
Aviso: AWS Migration Hub no admite clientes nuevos desde el 07/11/2025; los clientes actuales pueden seguir usándolo. Para capacidades parecidas, AWS recomienda AWS Transform. El servicio sigue apareciendo en las guías de examen.

Qué es

AWS Migration Hub es un panel central para planificar y seguir el progreso de una migración a AWS. Reúne el inventario recogido por Application Discovery Service, permite agrupar servidores en aplicaciones y muestra el estado de cada uno mientras se migra con herramientas de AWS (Application Migration Service, DMS (Database Migration Service)) o de socios. No migra nada por sí mismo.

Conceptos clave

  • Región de inicio: la región donde Migration Hub guarda los datos de descubrimiento y de seguimiento; se elige al empezar.
  • Aplicaciones: grupos de servidores que se migran y se siguen juntos.
  • Herramientas integradas: envían su estado a Migration Hub para verlo en un solo sitio.
  • Recomendaciones de instancias EC2 (Elastic Compute Cloud): propone tipos de instancia según el uso real recogido.
  • Funciones relacionadas: Strategy Recommendations (qué estrategia usar para cada aplicación), Orchestrator (plantillas de flujos de migración), Journeys y Refactor Spaces (modernización gradual hacia microservicios).

Casos de uso típicos

  • Seguir una migración grande con varios equipos y herramientas.
  • Agrupar servidores descubiertos en aplicaciones y planificar olas.
  • Informar a la dirección del avance de la migración.

Cuándo NO usarlo

  • Si eres cliente nuevo: usa AWS Transform.
  • Para migrar servidores o bases de datos: Application Migration Service o DMS; Migration Hub solo los sigue.
  • Para inventariar el entorno: Application Discovery Service (que vuelca sus datos aquí).

Comparativa con servicios parecidos

FaseServicio
Descubrir y evaluarApplication Discovery Service (y AWS Transform)
Seguir el progresoMigration Hub
Migrar servidoresApplication Migration Service (Transform MGN)
Migrar bases de datosDMS y SCT (Schema Conversion Tool)

Modelo de precios

Migration Hub no tiene coste; se pagan las herramientas de migración y los recursos que usen.

Seguridad y alta disponibilidad

  • Control de acceso con IAM (Identity and Access Management).
  • Los datos se guardan en la región de inicio elegida.
  • Solo guarda metadatos de seguimiento, no los datos migrados.

Trampas de examen

  • "Un único lugar para seguir el estado de la migración": Migration Hub.
  • Migration Hub no migra: las herramientas hacen el trabajo y le envían su estado.
  • "Dónde ver los datos de Application Discovery Service": Migration Hub, en la región de inicio.
  • "Qué estrategia de migración usar para cada aplicación": Strategy Recommendations.
