Amazon Managed Service for Apache Flink

En una frase: Procesa flujos en tiempo real con aplicaciones Java, SQL (Structured Query Language: lenguaje de consultas de bases de datos relacionales) o Python con estado
Categoría: Análisis (Analytics)
Certificaciones: SAP-C02
Documentación oficial: Documentación de Amazon Managed Service for Apache Flink ↗

Qué es

Amazon Managed Service for Apache Flink (antes Kinesis Data Analytics) ejecuta aplicaciones de Apache Flink, el motor de código abierto para procesar flujos de datos en tiempo real con estado: agregaciones por ventanas de tiempo, uniones de flujos, detección de patrones. AWS gestiona la infraestructura, el escalado y las copias del estado; tú escribes la lógica en Java, Scala, Python o SQL.

Conceptos clave

  • Aplicación: el código de Flink, normalmente leído de Kinesis Data Streams o MSK (Managed Streaming for Apache Kafka) y escrito en S3 (Simple Storage Service), OpenSearch, DynamoDB u otro flujo.
  • KPU (Kinesis Processing Unit: unidad de capacidad de Managed Service for Apache Flink: vCPU y memoria): unidad de procesamiento (vCPU y memoria) en la que se mide y se cobra la capacidad; escala automáticamente.
  • Estado y puntos de control: Flink guarda el estado de forma duradera para recuperarse sin perder ni duplicar resultados.
  • Instantáneas (snapshots): copias del estado para actualizar o restaurar la aplicación.
  • Studio notebooks: cuadernos de Apache Zeppelin para consultar flujos de forma interactiva con SQL, Python o Scala.

Casos de uso típicos

  • Paneles en tiempo real con métricas agregadas por minuto.
  • Detección de anomalías o fraude sobre flujos.
  • Enriquecer y transformar eventos antes de guardarlos.

Cuándo NO usarlo

  • Para cargar datos en S3 o Redshift sin lógica compleja: Data Firehose.
  • Para procesar cada registro de forma sencilla y sin estado: Lambda con Kinesis o MSK.
  • Para procesamiento por lotes: Glue o EMR (Elastic MapReduce).

Comparativa con servicios parecidos

NecesidadServicio
Procesamiento con estado y ventanas en tiempo realManaged Service for Apache Flink
Entrega a destinos sin códigoData Firehose

Modelo de precios

Se paga por hora de KPU usada (más una KPU adicional por aplicación para la orquestación) y por el almacenamiento de la aplicación y de las copias del estado. Los Studio notebooks suman KPU adicionales.

Seguridad y alta disponibilidad

  • Acceso a orígenes y destinos con un rol de IAM (Identity and Access Management); puede ejecutarse dentro de tu VPC (Virtual Private Cloud).
  • Puntos de control y reinicio automático ante fallos.
  • Escalado automático según la carga.

Trampas de examen

  • "Agregaciones por ventanas de tiempo sobre un flujo": Managed Service for Apache Flink.
  • "Kinesis Data Analytics": es el nombre anterior de este servicio.
  • "Solo cargar en S3": Data Firehose.
  • "Consultas interactivas con SQL sobre un flujo": Studio notebooks.
