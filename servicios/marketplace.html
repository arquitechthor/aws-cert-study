AWS Marketplace

En una frase: Tienda de software de terceros que compras y despliegas con tu factura de AWS
Categoría: Administración financiera en la nube (Cloud Financial Management)
Certificaciones: CLF-C02
Documentación oficial: Documentación de AWS Marketplace ↗

Qué es

AWS Marketplace es un catálogo digital de software, datos y servicios de terceros que funcionan en AWS: SaaS (Software as a Service: software que se usa como servicio), AMI (Amazon Machine Image: plantilla con el sistema operativo para arrancar instancias), contenedores, modelos de ML (Machine Learning: aprendizaje automático), conjuntos de datos y servicios profesionales. Se encuentran, se compran y se despliegan rápidamente, y se pagan en la factura de AWS, sin abrir un proceso de compra con cada proveedor.

Conceptos clave

  • Tipos de producto: SaaS, AMI, contenedores, modelos y algoritmos de ML, datos (con Data Exchange) y servicios profesionales.
  • Modelos de precio: gratis, por uso (por hora o por unidad), contratos anuales o plurianuales y BYOL (licencia propia).
  • Ofertas privadas: precios y condiciones negociados con el proveedor para tu cuenta.
  • Private Marketplace: catálogo curado con los productos aprobados por la empresa.
  • Facturación unificada: el gasto aparece en la factura de AWS y puede contar para compromisos de gasto con AWS.

Casos de uso típicos

  • Desplegar en minutos un cortafuegos o una solución de seguridad de un fabricante conocido.
  • Contratar un SaaS con la cuenta de AWS ya existente.
  • Limitar qué software pueden comprar los equipos.

Cuándo NO usarlo

  • Para servicios propios de AWS: se usan directamente desde la consola.
  • Para compartir datos entre empresas con suscripciones: AWS Data Exchange (que se integra con Marketplace).

Modelo de precios

El precio lo fija cada vendedor (gratis, por uso, por contrato o BYOL) y se cobra en la factura de AWS, junto a los recursos de AWS que use el producto (por ejemplo, las instancias EC2 (Elastic Compute Cloud) de una AMI).

Seguridad y alta disponibilidad

  • AWS revisa los productos publicados (por ejemplo, las AMI se analizan en busca de vulnerabilidades).
  • Private Marketplace limita qué productos se pueden suscribir.
  • El cliente sigue siendo responsable de configurar y proteger lo que despliega.

Trampas de examen

  • "Comprar software de terceros y pagarlo en la factura de AWS": Marketplace.
  • "Precio negociado con un proveedor": oferta privada.
  • "Solo productos aprobados por la empresa": Private Marketplace.
  • "Usar mi licencia actual": BYOL.
