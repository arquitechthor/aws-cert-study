Amazon SageMaker AI

En una frase: Plataforma para preparar datos, entrenar, ajustar y desplegar tus propios modelos de ML (Machine Learning: aprendizaje automático)
Categoría: Machine learning (Machine Learning)
Certificaciones: SAA-C03 SAP-C02 AIF-C01 CLF-C02
Documentación oficial: Documentación de Amazon SageMaker AI ↗

Qué es

Amazon SageMaker AI (antes Amazon SageMaker) es la plataforma de AWS para construir, entrenar y desplegar modelos de aprendizaje automático propios. Cubre todo el ciclo de vida: preparar los datos, experimentar, entrenar a gran escala, poner el modelo en producción y vigilarlo. AWS gestiona la infraestructura; tú decides el algoritmo y los datos. Es la opción cuando los servicios de IA (inteligencia artificial) ya entrenados (Rekognition, Comprehend…) no cubren el problema.

Conceptos clave

  • SageMaker Studio: el entorno web de trabajo, con cuadernos y acceso a todas las herramientas.
  • Preparación de datos: Data Wrangler (limpiar y transformar de forma visual), Ground Truth (etiquetar datos, con personas y con ayuda automática) y Feature Store (almacén de características para que entrenamiento e inferencia usen los mismos datos).
  • Entrenamiento: trabajos en instancias gestionadas que se crean, entrenan y se apagan. Con algoritmos integrados, con tu código en marcos como PyTorch o TensorFlow, o con tu contenedor. El entrenamiento con Spot gestionado abarata, y el ajuste automático de hiperparámetros busca la mejor configuración.
  • Sin escribir código: Canvas (interfaz visual para analistas), Autopilot (prueba modelos automáticamente) y JumpStart (catálogo de modelos preentrenados y modelos fundacionales listos para desplegar o ajustar).
  • Cuatro opciones de inferencia:
    • En tiempo real: punto de enlace siempre activo, baja latencia.
    • Sin servidor: para tráfico intermitente; escala a cero entre ráfagas.
    • Asíncrona: peticiones grandes o lentas en cola, casi en tiempo real.
    • Transformación por lotes: predicciones sobre un conjunto de datos completo, sin punto de enlace permanente.
  • MLOps (Machine Learning Operations: prácticas para llevar y mantener modelos en producción): Pipelines (flujos automatizados), Model Registry (catálogo y aprobación de versiones) y Model Monitor (detecta la deriva de los datos y de la calidad del modelo en producción).
  • IA responsable: Clarify (detecta sesgos y explica las predicciones) y Model Cards (documentación del modelo).

Casos de uso típicos

  • Modelos predictivos con datos propios: demanda, abandono de clientes, riesgo, mantenimiento.
  • Detección de fraude y sistemas de recomendación a medida.
  • Ajustar y desplegar modelos fundacionales de código abierto con control de la infraestructura.
  • Industrializar el aprendizaje automático: del cuaderno a un proceso repetible y auditado.

Cuándo NO usarlo

  • Si un servicio de IA preentrenado resuelve el problema (visión, texto, voz, traducción): Rekognition, Comprehend, Transcribe, Translate… Es más rápido y no exige conocimientos de ML.
  • Para usar modelos fundacionales por API (Application Programming Interface: interfaz para que los programas se comuniquen) sin gestionar infraestructura: Bedrock.
  • Para procesar datos a gran escala antes de entrenar: EMR (Elastic MapReduce) o Glue.
  • Si no hay datos suficientes ni de calidad: ningún modelo propio lo arregla.

Modelo de precios

Se paga por uso de cada componente: las instancias de los cuadernos, las de entrenamiento (por segundo), las de inferencia (por hora mientras el punto de enlace existe, o por uso en la opción sin servidor), el almacenamiento y el procesamiento de datos. Un punto de enlace en tiempo real olvidado sigue costando: es el descuido más habitual.

Seguridad y alta disponibilidad

  • Roles de ejecución de IAM (Identity and Access Management) para cada trabajo, con acceso solo a los datos necesarios.
  • Entrenamiento e inferencia dentro de tu VPC (Virtual Private Cloud), sin acceso a internet si se exige, y cifrado con KMS (Key Management Service) de datos, volúmenes y artefactos.
  • Puntos de enlace con varias instancias repartidas en distintas AZ (Availability Zone: zona de disponibilidad) y escalado automático.
  • Model Monitor y Clarify aportan vigilancia continua y trazabilidad para la gobernanza.

Trampas de examen

  • "Construir, entrenar y desplegar un modelo propio": SageMaker AI.
  • "Tráfico intermitente, sin pagar en reposo": inferencia sin servidor. "Peticiones grandes o de larga duración": asíncrona. "Predicciones sobre todo un conjunto de datos, sin necesidad de respuesta inmediata": transformación por lotes. "Baja latencia constante": tiempo real.
  • "Detectar sesgos" o "explicar predicciones": Clarify.
  • "El modelo empeora con el tiempo en producción": Model Monitor.
  • "Etiquetar datos": Ground Truth. "Sin código": Canvas.
  • "Modelos preentrenados y fundacionales listos para desplegar": JumpStart.
  • "Reducir el coste del entrenamiento": entrenamiento con Spot gestionado.
