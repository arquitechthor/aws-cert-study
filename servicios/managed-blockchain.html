Amazon Managed Blockchain

En una frase: Redes de libro mayor distribuido Hyperledger Fabric o Ethereum sin montar nodos
Categoría: Blockchain (Blockchain)
Certificaciones: SAP-C02
Documentación oficial: Documentación de Amazon Managed Blockchain ↗
Aviso: Amazon Managed Blockchain (AMB) dejará de admitir clientes nuevos el 29/10/2026 y dejará de funcionar el 29/09/2027. AWS recomienda migrar a nodos autogestionados en AWS o a proveedores externos (Ethereum, Bitcoin, Polygon), a proveedores de datos de blockchain (AMB Query) y, para Hyperledger Fabric, a otra red gestionada, a Fabric en EC2 (Elastic Compute Cloud) o EKS (Elastic Kubernetes Service), o a una base de datos de AWS.

Qué es

Amazon Managed Blockchain (AMB) permite usar cadenas de bloques sin montar ni mantener la infraestructura. AMB Access da nodos gestionados de blockchains públicas (Ethereum, Bitcoin, Polygon) y redes privadas Hyperledger Fabric entre varias organizaciones. AMB Query ofrece API (Application Programming Interface: interfaz para que los programas se comuniquen) para consultar datos de blockchains públicas. El servicio está en fin de vida.

Conceptos clave

  • Blockchain: registro distribuido e inmutable, compartido entre participantes que no necesitan confiar en una autoridad central.
  • Hyperledger Fabric: red privada y con permisos; cada organización miembro tiene sus nodos y las reglas se programan como chaincode.
  • Nodos de Ethereum, Bitcoin y Polygon: para leer y enviar transacciones sin sincronizar un nodo propio.
  • AMB Query: datos de saldos, transacciones y eventos mediante API.

Casos de uso típicos

  • Consorcios de empresas que comparten un registro sin un intermediario central (cadena de suministro, comercio).
  • Aplicaciones Web3 que necesitan acceso a blockchains públicas.

Cuándo NO usarlo

  • Si hay una única autoridad de confianza: una base de datos tradicional es más simple y barata.
  • Para proyectos nuevos, por su fin de soporte: nodos propios en EC2 o EKS, o proveedores externos.
  • Para un historial verificable de cambios en una base de datos propia: tablas de auditoría o registros inmutables en S3 (Simple Storage Service) con Object Lock.

Comparativa con servicios parecidos

NecesidadOpción
Varias organizaciones sin autoridad centralBlockchain (Fabric o pública)
Una sola organización, registro inmutableBase de datos con auditoría o S3 Object Lock

Modelo de precios

Fabric: por hora de miembro y de nodo, más almacenamiento y datos. Nodos públicos: por hora de nodo o por petición (acceso sin servidor). AMB Query: por petición.

Seguridad y alta disponibilidad

  • Acceso con IAM (Identity and Access Management) (o tokens de acceso) y cifrado con KMS (Key Management Service).
  • En Fabric, identidades de los miembros con su autoridad de certificación.
  • Acceso privado a la red desde tu VPC (Virtual Private Cloud) mediante PrivateLink.

Trampas de examen

  • "Varias empresas que no confían entre sí comparten un registro": Managed Blockchain.
  • "Hyperledger Fabric o Ethereum sin gestionar nodos": Managed Blockchain.
  • "Una sola autoridad central": no hace falta blockchain.
