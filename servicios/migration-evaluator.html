Migration Evaluator

En una frase: Estima el coste en la nube de tu centro de datos para preparar el caso de negocio
Categoría: Migración y transferencia (Migration and Transfer)
Certificaciones: CLF-C02
Documentación oficial: Documentación de Migration Evaluator ↗

Qué es

Migration Evaluator (antes TSO Logic) es un servicio gratuito de AWS para crear un caso de negocio de la migración: analiza el inventario y el uso real de los servidores locales, propone las instancias EC2 (Elastic Compute Cloud) y volúmenes EBS (Elastic Block Store) adecuados y compara el coste actual con varios escenarios en AWS, incluidas las opciones de licencias. Un equipo de AWS acompaña el proceso.

Conceptos clave

  • Recolector sin agente: se instala en local con acceso de solo lectura a VMware, Hyper-V, Windows, Linux, Active Directory y SQL Server.
  • Importación: también acepta exportaciones de otras herramientas o datos de Application Discovery Service.
  • Quick Insights: resumen de una página con el coste proyectado en AWS.
  • Caso de negocio: comparación del coste actual con varios escenarios futuros, incluido el aprovechamiento de licencias (BYOL).

Casos de uso típicos

  • Justificar económicamente una migración ante la dirección.
  • Dimensionar correctamente las instancias según el uso real, no lo aprovisionado.
  • Planificar licencias de Windows y SQL Server en AWS.

Cuándo NO usarlo

  • Para estimar el coste de una arquitectura nueva: AWS Pricing Calculator.
  • Para migrar los servidores: Transform MGN.
  • Para una evaluación con agentes de IA (inteligencia artificial) y planificación de olas: AWS Transform.

Modelo de precios

Migration Evaluator es gratuito.

Seguridad y alta disponibilidad

  • El recolector usa acceso de solo lectura.
  • Se recogen datos de configuración y uso, no los datos de negocio.

Trampas de examen

  • "Caso de negocio para migrar el centro de datos": Migration Evaluator.
  • "Estimar cuánto costará una arquitectura nueva": Pricing Calculator.
  • "TCO (Total Cost of Ownership: coste total de propiedad) actual frente a AWS": Migration Evaluator.
