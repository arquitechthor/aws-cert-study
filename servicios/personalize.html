Amazon Personalize

En una frase: Recomendaciones personalizadas en tiempo real como las de una tienda online
Categoría: Machine learning (Machine Learning)
Certificaciones: AIF-C01 SAP-C02
Documentación oficial: Documentación de Amazon Personalize ↗

Qué es

Amazon Personalize crea recomendaciones personalizadas (productos, contenidos, rankings) con la misma tecnología que usa Amazon.com, sin necesidad de saber de aprendizaje automático. Le das tus datos de interacciones (qué vio o compró cada usuario), de artículos y de usuarios; él entrena el modelo y lo sirve por API (Application Programming Interface: interfaz para que los programas se comuniquen) en tiempo real o por lotes.

Conceptos clave

  • Grupo de conjuntos de datos: interacciones, artículos y usuarios, importados desde S3 (Simple Storage Service) o enviados en tiempo real con un rastreador de eventos.
  • Recetas: algoritmos según el caso: personalización por usuario, artículos similares, ranking personalizado, populares o tendencias.
  • Recomendadores de dominio: configuraciones listas para comercio electrónico o vídeo bajo demanda.
  • Solución y versión de la solución: el modelo entrenado.
  • Campaña: despliegue para recomendaciones en tiempo real.
  • Inferencia por lotes: recomendaciones para muchos usuarios a S3, por ejemplo para correos.
  • Filtros: reglas de negocio (excluir lo comprado o lo agotado).

Casos de uso típicos

  • "Te puede interesar" en una tienda online.
  • Ordenar los resultados de búsqueda según cada usuario.
  • Recomendaciones en correos de marketing.

Cuándo NO usarlo

  • Si necesitas un modelo propio con control total: SageMaker AI.
  • Para generar textos o descripciones de productos: modelos de Bedrock.
  • Para buscar en documentos: Kendra.

Modelo de precios

Se paga por los datos ingeridos, las horas de entrenamiento y las recomendaciones servidas (capacidad de campaña en tiempo real o número de recomendaciones por lotes).

Seguridad y alta disponibilidad

  • Datos cifrados con KMS (Key Management Service) y usados solo para tus modelos.
  • Acceso a S3 mediante un rol de IAM (Identity and Access Management).
  • Las campañas son puntos de enlace gestionados y escalables.

Trampas de examen

  • "Recomendaciones de productos sin experiencia en ML": Personalize.
  • "Excluir artículos ya comprados": filtros.
  • "Recomendaciones para un envío masivo de correos": inferencia por lotes.
  • "Que las recomendaciones reaccionen a lo que hace el usuario ahora": rastreador de eventos en tiempo real.
