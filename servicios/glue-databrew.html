AWS Glue DataBrew

En una frase: Limpia y prepara datos con más de 250 transformaciones visuales, sin escribir código
Categoría: Análisis (Analytics)
Certificaciones: AIF-C01
Documentación oficial: Documentación de AWS Glue DataBrew ↗

Qué es

AWS Glue DataBrew es una herramienta visual de preparación de datos. Analistas y científicos de datos pueden explorar, perfilar, limpiar y normalizar datos (de S3 (Simple Storage Service), Redshift, bases de datos o el Catálogo de datos de Glue) eligiendo entre más de 250 transformaciones, sin programar. Es útil, por ejemplo, para preparar datos antes de entrenar un modelo de aprendizaje automático.

Conceptos clave

  • Conjunto de datos: referencia a los datos de origen.
  • Proyecto: sesión interactiva donde se ve una muestra y se aplican transformaciones.
  • Receta: lista de pasos de transformación guardada y reutilizable.
  • Trabajos: de receta (aplican la receta a todos los datos) o de perfil (estadísticas de cada columna: valores nulos, distintos, valores atípicos).
  • Reglas de calidad de datos: comprobaciones (duplicados, valores fuera de rango) validadas en los trabajos de perfil.
  • Datos sensibles: detección y enmascaramiento de información personal.

Casos de uso típicos

  • Preparar datos para entrenar modelos (rellenar nulos, normalizar, codificar categorías).
  • Detectar problemas de calidad antes de cargar un almacén de datos.
  • Enmascarar datos personales antes de compartirlos.

Cuándo NO usarlo

  • Para ETL (Extract, Transform, Load: extraer, transformar y cargar datos) complejo a gran escala con código: trabajos de Glue (Spark) o EMR (Elastic MapReduce).
  • Para preparar datos dentro de un flujo de ML (Machine Learning: aprendizaje automático) de SageMaker AI: SageMaker Data Wrangler.
  • Para consultas analíticas: Athena o Redshift.

Comparativa con servicios parecidos

NecesidadServicio
Preparación visual sin códigoGlue DataBrew
ETL con código a escalaGlue (Spark) o EMR
Preparación de datos para ML en SageMakerSageMaker Data Wrangler

Modelo de precios

Se paga por sesiones interactivas (bloques de 30 minutos) y por hora de nodo en los trabajos.

Seguridad y alta disponibilidad

  • Acceso a los datos con roles de IAM (Identity and Access Management).
  • Cifrado de los resultados con KMS (Key Management Service).
  • Detección y enmascaramiento de datos personales.

Trampas de examen

  • "Limpiar y preparar datos sin escribir código": Glue DataBrew.
  • "Estadísticas de calidad de cada columna": trabajo de perfil.
  • "Reutilizar los mismos pasos de limpieza": recetas.
  • "ETL a gran escala con código": Glue o EMR.
