AWS Global Accelerator

En una frase: Dos IP (Internet Protocol: dirección de red) estáticas anycast que llevan a tus usuarios por la red troncal de AWS
Categoría: Redes y entrega de contenido (Networking and Content Delivery)
Certificaciones: CLF-C02 SAA-C03 SAP-C02
Documentación oficial: Documentación de AWS Global Accelerator ↗

Qué es

AWS Global Accelerator da a tu aplicación direcciones IP estáticas anycast (dos IPv4 (Internet Protocol version 4: direcciones IP de 32 bits), o cuatro en doble pila) que se anuncian desde las ubicaciones de borde de AWS. El tráfico del usuario entra en la red troncal de AWS en la ubicación más cercana y viaja por ella hasta el punto de enlace sano más adecuado, en una o varias regiones. Mejora la latencia y la estabilidad frente a recorrer internet, y conmuta entre regiones sin depender del caché de DNS (Domain Name System: traduce nombres de dominio a direcciones IP).

Conceptos clave

  • Acelerador estándar: reparte el tráfico entre puntos de enlace regionales (balanceadores de aplicación o de red, instancias EC2 (Elastic Compute Cloud) o IP elásticas) según cercanía, estado y pesos.
  • Acelerador de enrutamiento personalizado: asigna cada usuario a una instancia EC2 y un puerto concretos de una subred (por ejemplo, partidas multijugador o sesiones de VoIP (Voice over IP: llamadas de voz por internet)).
  • Agentes de escucha (listeners): puertos y protocolo (TCP (Transmission Control Protocol: protocolo de transporte fiable) o UDP (User Datagram Protocol: protocolo de transporte sin conexión)) que acepta el acelerador.
  • Grupos de puntos de enlace: uno por región, con un dial de tráfico (qué porcentaje recibe esa región) y pesos por punto de enlace.
  • Comprobaciones de estado: si un punto de enlace o una región dejan de estar sanos, el tráfico pasa a otros sin cambiar las IP.
  • Afinidad de cliente: envía siempre al mismo usuario al mismo punto de enlace.
  • Conservar la IP del cliente: con balanceadores de aplicación e instancias EC2, el destino ve la IP real del usuario.
  • BYOIP (Bring Your Own IP: usar en AWS tus propios rangos de IP públicas): puedes usar tus propios rangos de IP.

Casos de uso típicos

  • Aplicaciones TCP o UDP no HTTP (juegos, IoT (Internet of Things: internet de las cosas: dispositivos conectados), VoIP) para usuarios de todo el mundo.
  • Clientes que deben permitir IP fijas en sus cortafuegos.
  • Conmutación por error entre regiones en segundos, sin esperar a que caduque el TTL (Time To Live: tiempo de vida antes de caducar) del DNS.
  • Despliegues azul/verde o pruebas por región moviendo el dial de tráfico.

Cuándo NO usarlo

  • Para cachear contenido web estático o dinámico cerca del usuario: CloudFront.
  • Si basta con resolver por latencia o conmutar por DNS y se aceptan los tiempos del TTL: Route 53.
  • Para una aplicación usada en una sola región por usuarios cercanos: probablemente no aporta lo que cuesta.

Modelo de precios

Se paga una tarifa fija por hora por cada acelerador (activo o no), un recargo por GB (Data Transfer-Premium) en el sentido dominante del tráfico, que depende de la región y la ubicación de borde, y las IP públicas IPv4 que usa.

Seguridad y alta disponibilidad

  • Las IP se sirven desde redes independientes (zonas de red aisladas); si una falla, la otra sigue.
  • Incluye la protección de Shield Standard frente a DDoS (Distributed Denial of Service: ataque que satura un servicio desde muchos orígenes), y se puede añadir Shield Advanced.
  • Los grupos de seguridad y las reglas de WAF (Web Application Firewall) de los balanceadores siguen funcionando.
  • Conmutación por error entre regiones con comprobaciones de estado.

Trampas de examen

  • "IP estáticas" o "lista blanca de IP fijas" para una aplicación global: Global Accelerator.
  • "UDP", "juegos", "VoIP" con usuarios globales: Global Accelerator, no CloudFront.
  • "Conmutación entre regiones sin depender del caché de DNS": Global Accelerator.
  • "Cachear imágenes o vídeo": CloudFront.
  • "Enviar a cada jugador a un servidor concreto": acelerador de enrutamiento personalizado.
  • "Probar una región nueva con el 10 % del tráfico": dial de tráfico del grupo de puntos de enlace.
