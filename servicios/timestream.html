Amazon Timestream

En una frase: Base de datos de series temporales para métricas y lecturas con marca de tiempo
Categoría: Base de datos (Database)
Certificaciones: SAP-C02
Documentación oficial: Documentación de Amazon Timestream ↗
Aviso: Timestream for LiveAnalytics (el motor sin servidor original) no admite clientes nuevos desde el 20/06/2025. Para cualquier carga de series temporales, AWS recomienda Timestream for InfluxDB.

Qué es

Amazon Timestream es la familia de bases de datos de series temporales de AWS: datos con marca de tiempo como métricas, lecturas de sensores o eventos. Tiene dos motores: Timestream for InfluxDB, que gestiona por ti bases de datos InfluxDB de código abierto, y Timestream for LiveAnalytics, sin servidor, que ya no admite clientes nuevos.

Conceptos clave

  • Series temporales: medidas con marca de tiempo, normalmente con etiquetas (dispositivo, región).
  • Timestream for InfluxDB: instancias gestionadas (con Multi-AZ y réplicas de lectura), API (Application Programming Interface: interfaz para que los programas se comuniquen) y herramientas de InfluxDB, consultas en milisegundos para análisis en tiempo real.
  • Timestream for LiveAnalytics: sin servidor, con nivel de memoria para datos recientes y nivel magnético para históricos, y consultas programadas.
  • Integraciones: IoT Core, Managed Service for Apache Flink, Grafana.

Casos de uso típicos

  • Telemetría de dispositivos IoT (Internet of Things: internet de las cosas: dispositivos conectados).
  • Métricas de aplicaciones e infraestructura.
  • Paneles de supervisión en tiempo real.

Cuándo NO usarlo

  • Para datos transaccionales: RDS (Relational Database Service), Aurora o DynamoDB.
  • Para datos industriales con modelos de activos: IoT SiteWise.
  • Para análisis históricos masivos con SQL (Structured Query Language: lenguaje de consultas de bases de datos relacionales): Redshift o Athena.

Comparativa con servicios parecidos

NecesidadServicio
Series temporales con InfluxDBTimestream for InfluxDB
Datos de equipos industrialesIoT SiteWise
Análisis histórico con SQLAthena o Redshift

Modelo de precios

InfluxDB: por hora de instancia y por almacenamiento. LiveAnalytics: por escrituras, almacenamiento en cada nivel y datos consultados.

Seguridad y alta disponibilidad

  • Cifrado en reposo con KMS (Key Management Service) y en tránsito con TLS (Transport Layer Security: cifrado de las conexiones).
  • InfluxDB en tu VPC (Virtual Private Cloud), con Multi-AZ para conmutar ante fallos.

Trampas de examen

  • "Datos con marca de tiempo de millones de dispositivos": Timestream.
  • "Ya usan InfluxDB": Timestream for InfluxDB.
  • "Cliente nuevo": InfluxDB, no LiveAnalytics.
  • "Datos transaccionales": no es Timestream.
