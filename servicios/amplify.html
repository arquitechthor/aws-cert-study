AWS Amplify

En una frase: Crea y aloja apps web y móviles full stack con autenticación y datos ya conectados
Categoría: Frontend web y móvil (Frontend Web and Mobile)
Certificaciones: CLF-C02 SAA-C03 DVA-C02 SAP-C02
Documentación oficial: Documentación de AWS Amplify ↗

Qué es

AWS Amplify es un conjunto de herramientas para crear y alojar aplicaciones web y móviles full stack. Amplify Hosting conecta tu repositorio Git y, con cada cambio, compila y publica la web (estática o con renderizado en servidor) en una CDN (Content Delivery Network: red de entrega de contenido). El backend de Amplify (Gen 2) se define con TypeScript y crea por ti autenticación con Cognito, datos con AppSync y DynamoDB, ficheros en S3 (Simple Storage Service) y funciones Lambda. Las bibliotecas y componentes de interfaz conectan el frontal con todo ello.

Conceptos clave

  • Amplify Hosting: CI/CD (Continuous Integration / Continuous Delivery: integración y entrega continuas) desde GitHub, GitLab, Bitbucket o CodeCommit; despliegues por rama, previsualizaciones de solicitudes de incorporación, dominios propios con certificado, renderizado en servidor (por ejemplo Next.js) y protección con contraseña de ramas.
  • Amplify Gen 2: el backend se describe como código TypeScript (sobre CDK) y cada desarrollador tiene su propio entorno aislado.
  • Categorías: auth (Cognito), data (AppSync y DynamoDB), storage (S3), functions (Lambda), y más integraciones con CDK.
  • Bibliotecas de Amplify: para JavaScript, Swift, Android y Flutter, y componentes de interfaz (por ejemplo, la pantalla de inicio de sesión).

Casos de uso típicos

  • Publicar una aplicación React, Vue, Angular o Next.js con CI/CD en minutos.
  • Prototipos y productos de equipos pequeños que quieren backend sin servidor sin montar la infraestructura a mano.
  • Aplicaciones móviles con inicio de sesión, datos en tiempo real y subida de ficheros.

Cuándo NO usarlo

  • Para backends complejos con arquitecturas muy a medida: CDK, CloudFormation o SAM (Serverless Application Model: extensión de CloudFormation para aplicaciones sin servidores) directamente.
  • Para una web estática muy sencilla sin CI/CD: S3 con CloudFront puede bastar.
  • Para aplicaciones en contenedores: ECS (Elastic Container Service), App Runner o similares.

Modelo de precios

Hosting: minutos de compilación, GB almacenados y servidos y peticiones de renderizado en servidor. Los recursos del backend (Cognito, AppSync, DynamoDB, S3, Lambda) se pagan con sus propias tarifas.

Seguridad y alta disponibilidad

  • HTTPS (HTTP Secure: HTTP cifrado con TLS) con certificados gestionados en dominios propios.
  • Autenticación con Cognito y reglas de autorización por usuario o grupo en los datos.
  • Rol de servicio de IAM (Identity and Access Management) para desplegar el backend.
  • La web se sirve desde la red de CloudFront.

Trampas de examen

  • "Desplegar una aplicación web o móvil full stack rápidamente": Amplify.
  • "CI/CD y alojamiento de una SPA (Single-Page Application: web de una sola página) desde Git": Amplify Hosting.
  • "Previsualizar cada solicitud de incorporación": previsualizaciones de Amplify Hosting.
  • "Inicio de sesión en la app móvil": Amplify con Cognito.
  • "Probar en dispositivos reales": Device Farm, no Amplify.
