AWS Budgets

En una frase: Fija límites de gasto o uso y te avisa, o actúa, cuando se superan o se prevé superarlos
Categoría: Administración financiera en la nube (Cloud Financial Management)
Certificaciones: SAA-C03 SAP-C02 AIF-C01 CLF-C02
Documentación oficial: Documentación de AWS Budgets ↗

Qué es

AWS Budgets permite definir presupuestos y recibir alertas cuando el gasto o el uso superan, o se prevé que superen, el importe fijado. Es la herramienta para controlar el gasto de forma proactiva: tú marcas el límite y AWS te avisa a tiempo, o incluso actúa por ti. No impide gastar por sí sola, salvo que configures una acción.

Conceptos clave

  • Tipos de presupuesto:
    • De coste: un importe en dinero.
    • De uso: una cantidad de uso (horas de instancia, gigabytes).
    • De utilización de instancias reservadas o de Savings Plans: avisa si lo comprometido se aprovecha por debajo de un umbral.
    • De cobertura de instancias reservadas o de Savings Plans: avisa si la parte del uso cubierta por compromisos baja de un umbral.
  • Periodo: diario, mensual, trimestral, anual o a medida (por ejemplo, la duración de un proyecto). El importe puede ser fijo, planificado mes a mes o ajustarse solo según el histórico.
  • Filtros: por servicio, cuenta de la organización, región, etiqueta de asignación de costes, categoría de costes y otras dimensiones.
  • Alertas: al llegar a un porcentaje o importe, sobre el gasto real o sobre el previsto. Se envían por correo, a un tema de SNS (Simple Notification Service) o a un canal de chat.
  • Acciones de presupuesto (budget actions): al saltar una alerta pueden, de forma automática o tras una aprobación, aplicar una política de IAM (Identity and Access Management), asociar una SCP (Service Control Policy: límite de permisos para las cuentas de una organización) o detener instancias concretas de EC2 (Elastic Compute Cloud) o de RDS (Relational Database Service).
  • Informes de presupuestos: un resumen periódico por correo del estado de los presupuestos.
  • Actualización: los datos se refrescan varias veces al día, no en tiempo real.

Casos de uso típicos

  • Aviso al llegar al 80 % del presupuesto mensual de la cuenta, y otro si la previsión supera el 100 %.
  • Un presupuesto por equipo o proyecto, filtrado por etiqueta o por cuenta.
  • Frenar un entorno de pruebas que se dispara: una acción que impide crear más recursos.
  • Vigilar que las instancias reservadas y los Savings Plans se aprovechan.
  • Controlar el gasto de un experimento de IA (entrenamiento, inferencia) con un presupuesto por etiqueta.

Cuándo NO usarlo

  • Para analizar en qué se ha gastado: Cost Explorer.
  • Para el detalle línea a línea de la factura: Cost and Usage Report.
  • Para detectar picos anómalos sin fijar umbrales: la detección de anomalías de costes.
  • Para una alarma sencilla sobre el total facturado: una alarma de facturación de CloudWatch también sirve, pero no prevé ni filtra tanto.

Modelo de precios

Crear presupuestos y recibir alertas es gratuito. Los presupuestos con acciones tienen un coste diario a partir del tercero (los dos primeros son gratuitos). Los informes de presupuestos se cobran por informe enviado.

Seguridad y alta disponibilidad

  • El acceso a los datos de facturación se controla con IAM; el usuario raíz debe haber habilitado el acceso de IAM a la facturación.
  • En una organización, la cuenta de administración puede crear presupuestos para todas las cuentas; las cuentas miembro, solo para sí mismas.
  • Las acciones se ejecutan con un rol de IAM que Budgets asume, con permisos acotados a lo que debe hacer.

Trampas de examen

  • "Recibir una alerta cuando el gasto supere o vaya a superar un importe": Budgets.
  • "Visualizar y analizar el gasto": Cost Explorer. Budgets alerta; Cost Explorer explica.
  • "Impedir automáticamente que se creen más recursos al superar el presupuesto": acción de presupuesto con una política de IAM o una SCP.
  • "Avisar si las instancias reservadas se usan poco": presupuesto de utilización.
  • La alerta puede basarse en la previsión, antes de que el gasto ocurra.
