Amazon WorkSpaces Applications

En una frase: Transmite aplicaciones de escritorio al navegador sin instalarlas en el equipo
Categoría: Computación para usuarios finales (End User Computing)
Certificaciones: CLF-C02 SAP-C02
Documentación oficial: Documentación de Amazon WorkSpaces Applications ↗
Aviso: Amazon WorkSpaces Applications es el nombre actual de Amazon AppStream 2.0, renombrado a finales de 2025 dentro de la familia WorkSpaces. El servicio y sus conceptos no cambian, y en los exámenes verás "AppStream 2.0": es esto mismo.

Qué es

Amazon WorkSpaces Applications (antes AppStream 2.0) transmite aplicaciones de escritorio (Windows o Linux) al navegador o a un cliente ligero. La aplicación se ejecuta en instancias gestionadas en AWS y el usuario solo recibe la imagen; no hay que instalar nada en su equipo ni copiar datos en él. Hay una única versión de cada aplicación que mantener y la capacidad escala con los usuarios.

Conceptos clave

  • Image Builder: instancia donde se instalan las aplicaciones para crear la imagen.
  • Flotas: instancias que ejecutan la imagen. Always-On (arranque inmediato), On-Demand (instancias paradas que arrancan en un par de minutos, más baratas) y Elastic (sin gestionar capacidad, con aplicaciones en discos virtuales).
  • Pila (stack): une una flota con políticas de usuario (portapapeles, descargas, almacenamiento persistente).
  • Usuarios: grupo de usuarios propio o federación SAML (Security Assertion Markup Language: estándar de inicio de sesión federado) con el proveedor corporativo.
  • Almacenamiento persistente: carpetas de usuario en S3 (Simple Storage Service) u otros servicios conectados.
  • Escalado automático de la flota según el uso.
  • Acceso de agentes de IA (inteligencia artificial) a las aplicaciones mediante herramientas MCP (novedad reciente).

Casos de uso típicos

  • Llevar a la nube una aplicación de escritorio heredada sin reescribirla.
  • Software pesado (CAD (Computer-Aided Design: diseño asistido por ordenador), ingeniería) para estudiantes desde el navegador, con GPU (Graphics Processing Unit: procesador gráfico, muy usado en ML).
  • Demostraciones y pruebas de software sin instalación.
  • Dar acceso a una aplicación a terceros sin entregarles datos.

Cuándo NO usarlo

  • Si cada usuario necesita un escritorio completo y persistente: WorkSpaces.
  • Si la aplicación ya es una web: no hace falta transmitirla (o WorkSpaces Secure Browser si se quiere aislar).

Comparativa con servicios parecidos

NecesidadServicio
Una aplicación de escritorio en el navegadorWorkSpaces Applications
Un escritorio completo por usuarioWorkSpaces
Webs internas desde un navegador aisladoWorkSpaces Secure Browser

Modelo de precios

Se paga por hora de instancia de la flota (en marcha o parada, según el tipo) y, en Windows, una tarifa mensual por usuario de la licencia de acceso de Microsoft. Las aplicaciones de Microsoft con licencia incluida se cobran por usuario y mes.

Seguridad y alta disponibilidad

  • Los datos y la aplicación se quedan en AWS; solo viajan píxeles cifrados.
  • Políticas de pila para limitar portapapeles, descargas e impresión.
  • Flotas en varias AZ (Availability Zone: zona de disponibilidad) y en tu VPC (Virtual Private Cloud), con acceso a recursos privados.
  • Autenticación federada con SAML y MFA (Multi-Factor Authentication: inicio de sesión con un segundo factor) del proveedor.

Trampas de examen

  • "Ejecutar una aplicación de escritorio desde el navegador sin instalarla": AppStream 2.0 (hoy WorkSpaces Applications).
  • "Escritorio completo y persistente": WorkSpaces.
  • "Arranque inmediato para los usuarios": flota Always-On.
  • "Uso esporádico y más barato, se acepta esperar": flota On-Demand.
  • "Sin gestionar capacidad": flota Elastic.
