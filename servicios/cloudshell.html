AWS CloudShell

En una frase: Terminal en el navegador ya autenticada, con las herramientas de línea de comandos
Categoría: Herramientas para desarrolladores (Developer Tools)
Certificaciones: DVA-C02
Documentación oficial: Documentación de AWS CloudShell ↗

Qué es

AWS CloudShell es una terminal en el navegador que se abre desde la consola de AWS. Ya está autenticada con las credenciales de la sesión de la consola y trae instaladas la AWS CLI (Command Line Interface: línea de comandos), la CLI de SAM (Serverless Application Model: extensión de CloudFormation para aplicaciones sin servidores), Git, Python, Node.js y otras herramientas sobre Amazon Linux. No hay que instalar nada ni guardar claves en el portátil, y no tiene coste adicional.

Conceptos clave

  • Credenciales: las del usuario o rol con el que se inició sesión en la consola; los permisos de IAM (Identity and Access Management) se aplican igual.
  • Almacenamiento persistente: 1 GB en el directorio $HOME por región, privado y gratuito; se borra si no se usa CloudShell en esa región durante 120 días.
  • Entorno efímero: todo lo que está fuera de $HOME se pierde al terminar la sesión.
  • Inactividad: la sesión termina tras 20–30 minutos sin actividad.
  • Entornos en VPC (Virtual Private Cloud): para llegar a recursos privados; no tienen almacenamiento persistente.
  • Subir y descargar ficheros entre el equipo y la terminal.

Casos de uso típicos

  • Ejecutar comandos de la CLI desde un equipo sin herramientas instaladas.
  • Scripts rápidos de administración o pruebas.
  • Conectar con recursos privados de una VPC desde un entorno en VPC.

Cuándo NO usarlo

  • Para tareas largas o programadas: Lambda, Batch o una instancia.
  • Para entrar en una instancia EC2 (Elastic Compute Cloud): Session Manager de Systems Manager.
  • Para desarrollar a diario con IDE (Integrated Development Environment: editor de código con herramientas de desarrollo): tu entorno local o Kiro.

Comparativa con servicios parecidos

NecesidadServicio
Terminal con la CLI ya autenticadaCloudShell
Terminal dentro de una instancia EC2Session Manager

Modelo de precios

CloudShell no tiene coste adicional; solo se pagan los recursos de AWS que crees o uses con él.

Seguridad y alta disponibilidad

  • No hay claves de acceso que guardar ni rotar en el equipo.
  • Los permisos son los de IAM de la sesión de la consola.
  • Los administradores pueden denegar su uso con políticas de IAM.

Trampas de examen

  • "Usar la AWS CLI sin instalarla ni configurar claves": CloudShell.
  • "Los ficheros desaparecieron al volver": estaban fuera de $HOME, o pasaron 120 días sin usar la región.
  • "Conectarse a una instancia EC2 sin SSH (Secure Shell: acceso remoto cifrado por terminal)": Session Manager, no CloudShell.
