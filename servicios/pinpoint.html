Amazon Pinpoint

En una frase: Campañas de marketing multicanal con segmentos de usuarios, recorridos y métricas
Categoría: Frontend web y móvil (Frontend Web and Mobile)
Certificaciones: SAP-C02
Documentación oficial: Documentación de Amazon Pinpoint ↗
Aviso: Amazon Pinpoint no admite clientes nuevos desde el 20/05/2025 y dejará de funcionar el 30/10/2026 (consola, segmentos, campañas, recorridos y análisis). Las API (Application Programming Interface: interfaz para que los programas se comuniquen) de SMS, voz, notificaciones push y OTP (One-Time Password: código de un solo uso) siguen como AWS End User Messaging. Alternativas: campañas salientes y Customer Profiles de Amazon Connect para la interacción, SES (Simple Email Service) para el correo y Kinesis para los eventos.

Qué es

Amazon Pinpoint es un servicio de comunicación con clientes: permite segmentar a los usuarios de una aplicación y enviarles campañas y recorridos (secuencias automáticas) por correo, SMS, notificaciones push o voz, midiendo los resultados. Está en fin de vida: no admite clientes nuevos y deja de funcionar el 30/10/2026, aunque sus canales de envío continúan como AWS End User Messaging.

Conceptos clave

  • Puntos de enlace (endpoints): cada destino (un correo, un teléfono, un dispositivo) con sus atributos.
  • Segmentos: grupos de usuarios según atributos o comportamiento.
  • Campañas: envíos a un segmento, puntuales o programados.
  • Recorridos (journeys): flujos de varios pasos según lo que hace cada usuario.
  • Análisis: aperturas, clics y conversiones; los eventos pueden enviarse a Kinesis.
  • End User Messaging: nombre actual de los canales SMS, MMS (Multimedia Messaging Service: mensajes móviles con imágenes o vídeo), push, WhatsApp y voz.

Casos de uso típicos

  • Campañas de marketing segmentadas en varias vías.
  • Recordatorios y mensajes según el comportamiento en la app.
  • Códigos de un solo uso por SMS (hoy en End User Messaging).

Cuándo NO usarlo

  • Para proyectos nuevos: Connect (campañas salientes y Customer Profiles), SES o End User Messaging.
  • Para correo transaccional o masivo: SES.
  • Para notificaciones entre sistemas: SNS (Simple Notification Service).

Modelo de precios

Se pagaba por usuario objetivo al mes, por mensajes enviados en cada canal y por eventos recogidos.

Seguridad y alta disponibilidad

  • Acceso con IAM (Identity and Access Management) y cifrado de los datos.
  • Respeto de las bajas y del consentimiento de los destinatarios, como en SES.
  • Planifica la migración antes del 30/10/2026.

Trampas de examen

  • "Campañas de marketing segmentadas por correo, SMS y push": en las guías, Pinpoint; hoy, Connect y End User Messaging.
  • "Correo transaccional": SES.
  • "Notificar a sistemas o a una cola": SNS.
