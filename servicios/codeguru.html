Amazon CodeGuru

En una frase: Revisa el código con aprendizaje automático y señala fallos y problemas de rendimiento
Categoría: Herramientas para desarrolladores (Developer Tools)
Certificaciones: SAP-C02
Documentación oficial: Documentación de Amazon CodeGuru ↗
Aviso: CodeGuru Reviewer no permite crear asociaciones de repositorio nuevas desde el 07/11/2025; solo sigue funcionando con las existentes. Para revisar código, AWS propone Amazon Inspector (escaneo de código) y Amazon Q Developer. CodeGuru Profiler sigue disponible.

Qué es

Amazon CodeGuru reúne dos herramientas que usan aprendizaje automático para mejorar el código. CodeGuru Profiler recoge datos de rendimiento de aplicaciones en ejecución y señala las líneas que más CPU (Central Processing Unit: procesador) o tiempo consumen, con recomendaciones. CodeGuru Reviewer revisaba automáticamente el código de los repositorios y de las solicitudes de incorporación en busca de errores, problemas de seguridad y malas prácticas; ya no admite repositorios nuevos.

Conceptos clave

  • Profiler: un agente ligero en aplicaciones Java (JVM) o Python, en EC2 (Elastic Compute Cloud), contenedores, Lambda o servidores locales.
  • Gráficos de llamas (flame graphs): muestran dónde se va el tiempo de CPU.
  • Recomendaciones y anomalías: detectan código caro o cambios de comportamiento, y estiman el ahorro.
  • Reviewer: comentarios automáticos en solicitudes de incorporación y escaneos completos del repositorio (Java y Python), incluida la detección de secretos en el código.

Casos de uso típicos

  • Encontrar qué método provoca picos de CPU en producción y reducir el coste de cómputo.
  • Analizar el uso de memoria (heap) de una aplicación Java.
  • (Clientes existentes) revisión automática de código en las solicitudes de incorporación.

Cuándo NO usarlo

  • Para revisar el código de un repositorio nuevo: Amazon Inspector (escaneo de código) o Q Developer.
  • Para trazar peticiones entre servicios: X-Ray.
  • Para métricas de infraestructura: CloudWatch.

Modelo de precios

Profiler se paga por hora de muestreo de cada aplicación perfilada (con capa gratuita para Lambda). Reviewer se pagaba por líneas de código analizadas al mes.

Seguridad y alta disponibilidad

  • El agente envía datos de rendimiento, no el código ni los datos de negocio.
  • Acceso con IAM (Identity and Access Management) y cifrado con KMS (Key Management Service).
  • El agente tiene un impacto mínimo en la aplicación.

Trampas de examen

  • "Las líneas de código más caras" o "reducir el uso de CPU": CodeGuru Profiler.
  • "Revisión automática de código con ML (Machine Learning: aprendizaje automático)": en preguntas antiguas, CodeGuru Reviewer; hoy, Inspector o Q Developer para repositorios nuevos.
  • "Qué microservicio es lento": X-Ray, no CodeGuru.
