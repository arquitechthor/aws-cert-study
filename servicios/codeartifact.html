AWS CodeArtifact

En una frase: Repositorio privado de paquetes npm, Maven o PyPI para compartir dependencias
Categoría: Herramientas para desarrolladores (Developer Tools)
Certificaciones: DVA-C02 SAP-C02
Documentación oficial: Documentación de AWS CodeArtifact ↗

Qué es

AWS CodeArtifact es un repositorio privado de paquetes de software gestionado. Los desarrolladores y las compilaciones descargan y publican paquetes con sus herramientas de siempre (npm, pip, Maven, Gradle, NuGet…), pero desde un lugar controlado por la empresa, que además puede guardar copia de los paquetes públicos que se usan.

Conceptos clave

  • Dominio: agrupa repositorios y guarda los paquetes una sola vez aunque estén en varios repositorios; se comparte entre cuentas con una política de dominio.
  • Repositorio: conjunto de paquetes al que apuntan las herramientas.
  • Repositorios ascendentes (upstream): si un paquete no está, se busca en el repositorio ascendente.
  • Conexión externa: enlaza un repositorio con uno público (npmjs, PyPI, Maven Central…) y guarda copia de lo descargado, aunque después desaparezca del origen.
  • Token de autorización: temporal (12 horas por defecto), se obtiene con la CLI (Command Line Interface: línea de comandos) y lo usan las herramientas de paquetes.
  • Controles de origen de paquetes: deciden si una versión puede venir de fuera o solo publicarse internamente, para evitar ataques de confusión de dependencias.

Casos de uso típicos

  • Publicar bibliotecas internas para que las usen otros equipos.
  • Controlar qué paquetes públicos se usan y conservar copia de ellos.
  • Compilaciones de CodeBuild en subredes privadas que necesitan dependencias sin salir a internet.

Cuándo NO usarlo

  • Para imágenes de contenedores: ECR (Elastic Container Registry).
  • Para código fuente: un repositorio Git.
  • Para ficheros binarios arbitrarios sin un gestor de paquetes: S3 (Simple Storage Service).

Modelo de precios

Se paga el almacenamiento de los paquetes por GB y mes, las peticiones y la transferencia de datos de salida, con una capa gratuita mensual.

Seguridad y alta disponibilidad

  • Acceso con IAM (Identity and Access Management) y políticas de dominio y de repositorio; tokens temporales.
  • Paquetes cifrados con KMS (Key Management Service).
  • Puntos de enlace de VPC (Virtual Private Cloud) para usarlo sin internet.
  • Controles de origen para frenar la confusión de dependencias.

Trampas de examen

  • "Repositorio privado de npm, PyPI o Maven": CodeArtifact.
  • "Conservar copia de los paquetes públicos que usamos": conexión externa.
  • "Compartir paquetes entre cuentas": un dominio con política de dominio.
  • "npm install falla con 401": el token caducó; obtener otro con la CLI.
  • "Imágenes Docker": ECR, no CodeArtifact.
