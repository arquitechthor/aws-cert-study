AWS Firewall Manager

En una frase: Impone reglas de cortafuegos y de protección DDoS iguales en todas tus cuentas
Categoría: Seguridad, identidad y cumplimiento (Security, Identity, and Compliance)
Certificaciones: SAA-C03 SAP-C02 CLF-C02
Documentación oficial: Documentación de AWS Firewall Manager ↗

Qué es

AWS Firewall Manager permite definir una vez las reglas de protección de red y de aplicación, y aplicarlas automáticamente en todas las cuentas de una organización de AWS Organizations. No es un cortafuegos más: es la capa de gestión que despliega y vigila los que ya existen (WAF, Shield Advanced, grupos de seguridad…). Su valor está en que cubre también las cuentas y los recursos que se creen en el futuro.

Conceptos clave

  • Requisitos previos: AWS Organizations con todas las funciones, una cuenta designada como administrador de Firewall Manager y AWS Config activado en las cuentas (lo usa para descubrir los recursos).
  • Política de seguridad: la unidad de trabajo. Indica el tipo de protección, las reglas y el alcance: qué cuentas u OU (Organizational Unit: unidad organizativa de AWS Organizations), qué tipos de recurso y, si se quiere, qué etiquetas.
  • Tipos de política:
    • AWS WAF: grupos de reglas en los balanceadores de aplicación, API Gateway y CloudFront.
    • Shield Advanced: protección frente a DDoS (Distributed Denial of Service: ataque que satura un servicio desde muchos orígenes) en los recursos del alcance.
    • Grupos de seguridad: un grupo común en todos los recursos, o auditoría de grupos demasiado permisivos o sin usar.
    • ACL (Access Control List: lista de control de acceso) de red.
    • AWS Network Firewall: despliega cortafuegos y reglas en las VPC (Virtual Private Cloud).
    • DNS Firewall de Route 53 Resolver: asocia grupos de reglas a las VPC.
    • Cortafuegos de terceros contratados en AWS Marketplace.
  • Corrección automática: la política puede solo informar de los recursos que no cumplen o aplicar la protección automáticamente.
  • Panel de cumplimiento: qué cuentas y recursos cumplen cada política.
  • Las políticas son regionales, salvo las de CloudFront, que se crean en la región global.

Casos de uso típicos

  • Garantizar que todos los balanceadores y API (Application Programming Interface: interfaz para que los programas se comuniquen) de la organización llevan las reglas básicas de WAF.
  • Proteger con Shield Advanced todos los recursos expuestos, incluidos los nuevos.
  • Detectar y corregir grupos de seguridad que abren puertos a todo internet.
  • Desplegar Network Firewall de forma uniforme en las VPC de la organización.

Cuándo NO usarlo

  • Con una sola cuenta o pocos recursos: configura WAF o Shield directamente.
  • Para limitar permisos en las cuentas: SCP (Service Control Policy: límite de permisos para las cuentas de una organización) de AWS Organizations.
  • Para evaluar cualquier otra configuración de los recursos: AWS Config.
  • Para ver hallazgos de seguridad agregados: Security Hub.

Modelo de precios

Se paga una cuota mensual por política y región, más lo que cuesten los recursos que la política crea (reglas de WAF, cortafuegos, reglas de AWS Config). Las políticas de WAF y de Shield Advanced no tienen coste adicional para los clientes suscritos a Shield Advanced.

Seguridad y alta disponibilidad

  • El administrador de Firewall Manager es una cuenta muy sensible: conviene que sea la de seguridad, no la de administración de la organización.
  • Se pueden designar varios administradores, cada uno con un alcance (cuentas, regiones, tipos de política).
  • Los equipos de cada cuenta no pueden quitar las protecciones impuestas por una política.
  • Los incumplimientos se envían a Security Hub.

Trampas de examen

  • "Gestionar de forma centralizada las reglas de WAF en varias cuentas": Firewall Manager.
  • "Que los recursos nuevos queden protegidos automáticamente": política de Firewall Manager con corrección automática.
  • "Auditar los grupos de seguridad de toda la organización": política de grupos de seguridad de Firewall Manager.
  • Requisitos: Organizations y AWS Config.
  • WAF, Shield y Network Firewall protegen; Firewall Manager los administra.
