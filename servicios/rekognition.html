Amazon Rekognition

En una frase: Analiza imágenes y vídeos para detectar caras, objetos, texto y contenido inapropiado
Categoría: Machine learning (Machine Learning)
Certificaciones: SAA-C03 SAP-C02 AIF-C01 CLF-C02
Documentación oficial: Documentación de Amazon Rekognition ↗
Aviso: desde el 30/04/2026, dos funciones de Rekognition no están disponibles para clientes nuevos: el análisis de vídeo en streaming y el análisis masivo de imágenes. AWS recomienda procesar los fotogramas o los lotes con la API (Application Programming Interface: interfaz para que los programas se comuniquen) de imágenes. El resto del servicio no cambia.

Qué es

Amazon Rekognition es un servicio de visión artificial ya entrenado. Le das una imagen o un vídeo y devuelve qué hay en él, con un nivel de confianza para cada resultado. No hace falta saber de aprendizaje automático ni reunir datos de entrenamiento: se usa con una llamada a la API.

Conceptos clave

  • Etiquetas: objetos, escenas, actividades y conceptos ("coche", "playa", "boda").
  • Moderación de contenido: detecta contenido explícito, violento u ofensivo, con categorías y niveles de confianza.
  • Texto en la imagen: lee rótulos, matrículas o carteles. Para documentos, mejor Textract.
  • Análisis de caras: detecta caras y atributos (gafas, ojos abiertos, emoción aparente).
  • Comparación y búsqueda de caras: compara dos caras, o busca una cara dentro de una colección de caras indexadas, para verificar identidades.
  • Prueba de vida (Face Liveness): comprueba que hay una persona real ante la cámara y no una foto o un vídeo.
  • Reconocimiento de famosos y detección de equipos de protección (casco, mascarilla, guantes).
  • Etiquetas personalizadas (Custom Labels): entrenas un modelo con unas decenas o cientos de imágenes propias para detectar lo específico de tu negocio (un logotipo, un defecto de fabricación).
  • Vídeo almacenado: análisis asíncrono de vídeos guardados en S3 (Simple Storage Service); el resultado se avisa por SNS (Simple Notification Service).
  • Umbral de confianza: tú decides a partir de qué porcentaje aceptas un resultado.

Casos de uso típicos

  • Moderar las imágenes y los vídeos que suben los usuarios.
  • Hacer buscable una biblioteca de fotos o de vídeo por su contenido.
  • Verificación de identidad en el alta de clientes: selfi frente a documento, con prueba de vida.
  • Seguridad laboral: comprobar el uso de equipos de protección.
  • Control de calidad visual con etiquetas personalizadas.

Cuándo NO usarlo

  • Para extraer texto, tablas y formularios de documentos: Textract.
  • Para analizar audio o lo que se dice en un vídeo: Transcribe.
  • Para un modelo de visión totalmente a medida o con arquitecturas propias: SageMaker AI.
  • Para generar imágenes o describirlas con lenguaje libre: modelos multimodales en Bedrock.
  • En decisiones con consecuencias para las personas, no uses el resultado sin revisión humana.

Modelo de precios

En imágenes se paga por imagen analizada, según la función. En vídeo, por minuto de vídeo. Las colecciones de caras cobran además el almacenamiento de los vectores de cara. En las etiquetas personalizadas se pagan las horas de entrenamiento y las horas que el modelo está en ejecución para inferencia.

Seguridad y alta disponibilidad

  • Acceso con IAM (Identity and Access Management); las imágenes se leen de S3 o se envían en la petición.
  • Las colecciones no guardan las imágenes, sino vectores que representan cada cara.
  • IA (inteligencia artificial) responsable: los resultados son probabilidades. En usos sensibles, como la identificación de personas, hay que usar umbrales altos y revisión humana, y respetar la normativa aplicable.
  • Cifrado en tránsito y en reposo; servicio gestionado que escala solo.

Trampas de examen

  • "Analizar imágenes o vídeos", "detectar objetos", "reconocer caras": Rekognition.
  • "Detectar contenido inapropiado en lo que suben los usuarios": moderación de contenido de Rekognition.
  • "Texto de un documento escaneado, con tablas": Textract, no Rekognition.
  • "Detectar el logotipo de la empresa o un defecto concreto": etiquetas personalizadas.
  • "Verificar que el usuario es una persona real": prueba de vida.
  • Vídeo guardado en S3: análisis asíncrono con aviso por SNS.
