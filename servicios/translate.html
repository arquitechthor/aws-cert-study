Amazon Translate

En una frase: Traduce textos entre decenas de idiomas con traducción automática neuronal
Categoría: Machine learning (Machine Learning)
Certificaciones: SAA-C03 SAP-C02 AIF-C01 CLF-C02
Documentación oficial: Documentación de Amazon Translate ↗

Qué es

Amazon Translate es un servicio de traducción automática neuronal: traduce texto de un idioma a otro con modelos de aprendizaje profundo, que tienen en cuenta el contexto de la frase completa. Cubre decenas de idiomas, responde en tiempo real y permite adaptar las traducciones al vocabulario y al estilo de tu empresa.

Conceptos clave

  • Traducción en tiempo real: una llamada a la API (Application Programming Interface: interfaz para que los programas se comuniquen) devuelve al momento la traducción de un texto o de un documento.
  • Traducción por lotes: trabajos asíncronos sobre conjuntos de documentos guardados en S3 (Simple Storage Service) (texto, HTML (HyperText Markup Language: lenguaje de las páginas web), Word, Excel, PowerPoint…), conservando el formato.
  • Detección automática del idioma de origen: si no lo indicas, lo detecta (con Comprehend).
  • Terminología personalizada: un glosario que fija cómo se traducen ciertos términos: nombres de marca, de producto, tecnicismos.
  • Datos paralelos (Active Custom Translation): ejemplos de traducciones tuyas para que el resultado imite tu estilo y tono, sin entrenar un modelo.
  • Formalidad: registro formal o informal en los idiomas que lo distinguen.
  • Enmascarado de palabras malsonantes y brevedad (traducciones más cortas, útil para subtítulos).
  • Etiquetas de no traducir: marcan fragmentos que deben quedar tal cual.

Casos de uso típicos

  • Localizar sitios web, aplicaciones y catálogos de productos.
  • Chat y soporte multilingüe en tiempo real.
  • Traducir contenido generado por los usuarios: reseñas, comentarios, foros.
  • Analizar textos en muchos idiomas: se traducen a uno y después se analizan con Comprehend.
  • Subtítulos en otros idiomas: Transcribe, Translate y, si se quiere doblaje, Polly.

Cuándo NO usarlo

  • Si la entrada es audio: antes Transcribe. Si es un documento escaneado: antes Textract.
  • Para analizar el sentimiento o las entidades: Comprehend.
  • Para textos legales, médicos o de marca donde un error tiene consecuencias: úsalo como borrador, con revisión humana.
  • Para reescribir, resumir o adaptar creativamente un texto: un modelo de Bedrock.

Modelo de precios

Se paga por número de caracteres traducidos. La traducción con datos paralelos y la de documentos tienen tarifas propias, más altas que la estándar.

Seguridad y alta disponibilidad

  • Acceso con IAM (Identity and Access Management); los trabajos por lotes usan un rol para leer y escribir en S3.
  • Cifrado en tránsito y, en los trabajos por lotes, cifrado de la salida con KMS (Key Management Service).
  • Acceso privado desde una VPC (Virtual Private Cloud) mediante PrivateLink.
  • Las terminologías y los datos paralelos se guardan cifrados y son privados de tu cuenta.

Trampas de examen

  • "Traducir", "localizar el contenido" o "soporte multilingüe": Translate.
  • "Los nombres de marca no deben traducirse" o "deben traducirse siempre igual": terminología personalizada.
  • "Que la traducción tenga el estilo de nuestras traducciones anteriores": datos paralelos.
  • "Miles de documentos de una vez": traducción por lotes desde S3.
  • "Subtítulos traducidos de un vídeo": Transcribe y después Translate.
  • Translate no analiza ni resume: solo traduce.
